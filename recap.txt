### 2. Book Now / Driver Notification Crash — FIXED
Root causes in Laravel (`Modules/Taxido`):
- **Redis::georadius() TypeError**: `georadius(key, lng, lat, radius, 'km', 'ASC')` — options must be array, not string.  
  Fix: `georadius(..., ['ASC'])` in `DriverStateService::findNearestDrivers`.
- **Metadata TTL mismatch**: Redis GEO members never expire; driver metadata expires after 600s. `findNearestDrivers` skipped drivers with missing metadata → empty driver list → "no driver available" error (bidding mode).  
  Fix: DB fallback in `findNearestDrivers` — hydrate metadata from `Driver` model when Redis key missing.
- Result: `POST /api/rideRequest` now returns HTTP 200, creates ride, broadcasts `DriverRideRequestBroadcast` to nearest driver(s), and queues FCM push (`InstantRideRequestNotification`).
- `BROADCAST_DRIVER=log` in .env → Reverb events go to log file; Reverb server not running (supervisor points to non-existent `/var/www/livriko.fr/admin`). Driver notification path relies on FCM push (firebase.json present, `pushNotification()` helper wired).
