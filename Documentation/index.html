What is Livriko?

Livriko is a comprehensive mobility platform that connects passengers, drivers, and businesses through a seamless digital experience. Built as a fork of Taxido by Pixelstrap, it offers ride-hailing, vehicle rental, and parcel delivery services from a single mobile application.

Key Capabilities

  • Real-time GPS tracking with live driver locations
  • Scheduled ride booking for advance planning
  • Multiple secure payment options — Cash, Stripe, PayPal, wallets
  • Ride history and digital receipts
  • Bidirectional driver-customer ratings
  • SOS emergency safety features
  • Fleet management tools
  • Surge pricing and dynamic fare calculation
  • Multi-language and multi-currency support
  • Push notifications via Firebase Cloud Messaging
  • Real-time updates via Laravel Reverb WebSockets
Open & Extensible
Livriko is designed to be white-labeled and customized for any market. Its modular architecture lets you enable or disable services, add new payment gateways, and adapt the platform to local regulations.

Architecture Overview

Livriko is composed of three tightly integrated components.

1
Laravel 12 · PHP 8.2

Backend API

RESTful API with Laravel Sanctum authentication, a full admin panel, and 20+ business modules covering ride logic, payments, fleets, notifications, and analytics.

2
React Native 0.82.1

User App

The passenger-facing mobile application with Google Maps integration, multiple payment options, ride booking, scheduling, real-time tracking, and ride history.

3
React Native 0.82.1

Driver App

The driver-facing mobile application with turn-by-turn navigation, earnings dashboard, background location tracking, online/offline toggle, and SOS features.

Communication Layer
All three components communicate via RESTful APIs. Real-time features (ride status updates, driver location pings, chat messages) use Laravel Reverb WebSockets, while push notifications are delivered through Firebase Cloud Messaging (FCM).

Services

Livriko provides three core services from a single app.

Ride Booking

Request reliable rides with verified drivers. Choose from standard, premium, or shared rides with real-time tracking, fare estimation, and scheduled bookings.

Vehicle Rental

Rent vehicles for personal or business use. Manage hourly or daily packages, track rental duration, and handle deposits and returns seamlessly.

Parcel Delivery

Send and track packages quickly and securely. Real-time delivery tracking, proof of delivery, and multi-stop routing for efficient logistics.
