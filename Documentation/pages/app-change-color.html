Change App Color

Customize the theme colors of the Livriko User App and Driver App. Colors control the visual identity of the app, including buttons, headers, status bars, and accent elements.

Livriko Brand Colors

The default Livriko color palette is defined as follows. Use these values when rebranding the app to maintain visual consistency:

Color Name Hex Value Usage
Primary Blue #1070b7 Main brand color, buttons, headers, links
Accent Red #be1823 Error states, alerts, critical actions
Price Green #20B149 Price display, earnings, success states
Dark #1F1F1F Text, backgrounds, dark mode elements
Active Blue #3F8FDA Active states, selected items, toggles
Complete Yellow #FFB400 Completed status, star ratings, warnings
Schedule Purple #7F00FF Scheduled rides, premium features
White #FFFFFF Card backgrounds, text on dark surfaces
Light Gray #F5F5F5 Page backgrounds, dividers

User App Colors

Edit the color theme file to change the User App colors. This file is imported throughout the app for consistent theming:

File: Taxido_user/src/themes/appColors.tsx

// Taxido_user/src/themes/appColors.tsx
export const appColors = {
  primary: '#1070b7',       // Main brand color
  alertRed: '#be1823',      // Error / alert accent
  successGreen: '#20B149',  // Success / price color
  dark: '#1F1F1F',          // Text and dark backgrounds
  activeBlue: '#3F8FDA',    // Active states and toggles
  completeYellow: '#FFB400', // Completed status and ratings
  schedulePurple: '#7F00FF', // Scheduled ride features
  // ... add more colors as needed
};
Note

The User App uses src/themes/ (plural) while the Driver App uses src/theme/ (singular). Make sure you edit the correct file for each app.

Driver App Colors

Edit the color theme file for the Driver App. Note that the Driver App uses a singular theme directory name, unlike the User App which uses themes:

File: Taxido_driver/src/theme/appColors.tsx

// Taxido_driver/src/theme/appColors.tsx
export const appColors = {
  primary: '#1070b7',       // Main brand color

Android Native Colors

For Android-specific color changes (e.g., status bar, navigation bar, splash screen), edit the native color resource files:

File: Taxido_user/android/app/src/main/res/values/colors.xml

<?xml version="1.0" encoding="utf-8"?>
<resources>
    <color name="colorPrimary">#1070b7</color>
    <color name="colorPrimaryDark">#0D5A94</color>
    <color name="colorAccent">#be1823</color>
    <color name="statusBarColor">#1070b7</color>
    <color name="navigationBarColor">#1F1F1F</color>
</resources>

Update the same file for the Driver App at:

Taxido_driver/android/app/src/main/res/values/colors.xml

iOS Native Colors

For iOS-specific color changes (e.g., status bar tint, launch screen accent color), update the asset catalog files. These colors apply to native UI elements outside of the React Native layer:

File: Taxido_user/ios/Taxido_user/Assets.xcassets/AccentColor.colorset/Contents.json

You can edit this file directly or use Xcode's visual asset catalog editor to pick the new color values.

Tip

Use a color picker tool like Coolors or Adobe Color to generate a harmonious color palette for your rebrand.

Consistency Checklist

When changing app colors, ensure you update all of the following locations for a consistent visual experience across the entire app:

Platform File What Changes
React Native (User) src/themes/appColors.tsx In-app UI colors
React Native (Driver) src/theme/appColors.tsx In-app UI colors
Android (User) android/app/src/main/res/values/colors.xml Status bar, nav bar, native elements
Android (Driver) android/app/src/main/res/values/colors.xml Status bar, nav bar, native elements
iOS (User) ios/Taxido_user/Assets.xcassets/ Accent color, launch screen tint
iOS (Driver) ios/Taxido_driver/Assets.xcassets/ Accent color, launch screen tint

Testing Color Changes

After updating colors, rebuild the app and verify the changes on both platforms:

  • Headers and navigation bars — Should reflect the primary brand color
  • Buttons — Primary action buttons should use the primary color
  • Status bar — On Android, the status bar color should match the header
  • Error states — Validation errors and alerts should use the accent red
  • Success states — Price displays and confirmations should use the success green
  • Tab indicators — Active tabs should highlight with the active blue color
  • Rating stars — Star ratings should display in the complete yellow color
Tip

Test your color changes on both light and dark backgrounds to ensure sufficient contrast and accessibility. Use a contrast checker tool to verify WCAG 2.1 compliance for text readability.
