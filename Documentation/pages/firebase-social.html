Social Login

Livriko supports Google, Facebook, and Apple Sign-In for seamless user authentication. Each provider requires specific Firebase and platform configuration.

Prerequisite

Social Login providers (Google, Apple) require the Firebase Blaze (pay-as-you-go) plan. The Spark (free) plan does not support social authentication. See the Billing page for details.

Google Sign-In

Google Sign-In allows users to sign in with their Google account. This is the most common social login provider.

Firebase Setup

Enable Google Provider

Go to Firebase Console → Authentication → Sign-in method. Click on Google and enable it. Set a support email address.

Enable Email/Password Fallback

Also enable Email/Password as a fallback sign-in method for users who don't have a Google account.

Android Configuration

Add SHA Key

Add your SHA-1 key to the Firebase project (see SHA Key page).

Download Updated Config

After adding the SHA key, download an updated google-services.json from Firebase Console.

Replace Config File

Place the updated file in android/app/ and rebuild the app.

iOS Configuration

Xcode Signing

In Xcode, go to your target's Signing & Capabilities. Ensure the correct Team ID and Bundle Identifier are set.

Update GoogleService-Info.plist

Download the updated GoogleService-Info.plist from Firebase and replace the existing file in your ios/ directory.

Rebuild

Rebuild the iOS app. Google Sign-In should now work on iOS.

Facebook Login

Facebook Login allows users to sign in with their Facebook account. This requires additional configuration beyond Firebase.

Create Facebook App

Go to Facebook Developers

Visit developers.facebook.com and create a new app of type "Consumer".

Add Facebook Login Product

In your Facebook app dashboard, add the "Facebook Login" product and configure the OAuth redirect URI.

Get App ID and Secret

Copy the App ID and App Secret from the Facebook app settings.

Configure in Firebase

Enable Facebook in Firebase

Go to Firebase Console → Authentication → Sign-in method. Enable Facebook and enter your Facebook App ID and App Secret.

Configure OAuth Redirect

Set the OAuth redirect URI in your Facebook app settings to the Firebase callback URL.

Configure in Livriko Admin

Enter the Facebook credentials in the Livriko admin panel:

# In Settings → Social Login:
Facebook Client ID = your-facebook-app-id
Facebook Client Secret = your-facebook-app-secret

Apple Sign-In

Apple Sign-In is required for apps on the App Store if you offer any other social login providers.

Apple Developer Setup

Create an App ID

In the Apple Developer Console, create an App ID with the "Sign In with Apple" capability enabled.

Create a Services ID

Create a Services ID for web-based authentication. Configure the redirect URL and return URLs.

Create a Key

Create a new key with the "Sign in with Apple" capability. Download the .p8 file.

Configure in Firebase

Go to Firebase Console → Authentication → Sign-in method → Apple and enable it. Enter the following details:

Field Description
Service ID Your Apple Services ID (e.g., com.yourcompany.livriko)
Team ID Your Apple Developer Team ID (10-character string)
Key ID The Key ID from your Apple Developer account
Private Key (.p8) Upload the .p8 authentication key file

Configure in Livriko Admin

# In Settings → Social Login:
Apple Client ID = your-apple-services-id
Apple Team ID = your-team-id
Apple Key ID = your-key-id
Apple Private Key = contents-of-your-p8-file
