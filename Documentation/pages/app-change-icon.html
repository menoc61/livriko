Change App Icon

Replace the default Livriko app icons with your custom branding on both Android and iOS. This guide covers icon replacement for the User App and Driver App across all required sizes.

Tip

Start with a high-resolution source image (1024 x 1024 px) and resize it for each required size. This ensures crisp icons across all device densities. Use an online icon generator like appicon.co or App Icon Maker for quick resizing.

User App — Android

Replace the launcher icons in the User App Android res directories. You must replace both ic_launcher.png and ic_launcher_round.png in each density folder. The round icon is used on devices that support circular icon masking:

User App — iOS

Replace the icons in the User App AppIcon asset catalog. The asset catalog is the standard way to manage app icons in Xcode and handles all required sizes automatically based on the device:

Taxido_user/ios/Taxido_user/Images.xcassets/AppIcon.appiconset/

Update the Contents.json file to point to your new icon files, or use Xcode's asset catalog editor to drag and drop the icons directly. The asset catalog handles all required sizes automatically.

Tip

In Xcode, open Assets.xcassets, select AppIcon, and drag your icon files into the appropriate slots. Xcode will validate the sizes and warn you if any are missing or incorrectly sized.

Adaptive Icons (Android 8.0+)

Android 8.0 and above use adaptive icons, which separate the foreground and background layers. This allows the system to apply different shapes (circle, squircle, etc.) while keeping your icon looking good. To customize the adaptive icon, edit the following XML files:

Foreground: Taxido_user/android/app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml

<?xml version="1.0" encoding="utf-8"?>
<adaptive-icon xmlns:android="http://schemas.android.com/apk/res/android">
    <background android:drawable="@color/ic_launcher_background"/>
    <foreground android:drawable="@mipmap/ic_launcher_foreground"/>
</adaptive-icon>

Place your foreground image at 432 x 432 px in the mipmap-anydpi-v26 directory. The system will automatically crop it to the correct shape based on the device's icon mask settings.

Note

The adaptive icon background can be a solid color (defined in colors.xml) or a drawable resource. For a simple branded look, use a solid color that matches your primary theme color.

Warning

After replacing icons, perform a clean build. Delete the build folder and for iOS, also clean the DerivedData folder to ensure the new icons are picked up by the system.

# Android: clean build
cd Taxido_user/android && ./gradlew clean && cd ../..

# iOS: clean derived data
rm -rf ~/Library/Developer/Xcode/DerivedData/Taxido_user-*

Verifying Icon Changes

After replacing the icons and performing a clean build, verify the changes on your device or emulator:

  • Home screen — The app icon should display your new custom icon clearly
  • App drawer (Android) — Verify the icon appears correctly in the app list
  • Settings — The icon should appear in device settings app list
  • Push notifications — The notification icon may require separate configuration on Android
  • Spotlight search (iOS) — The icon should appear correctly in search results
  • Share sheet (iOS) — The icon should display when sharing content from the app
Tip

On Android, if the notification icon appears as a solid white square, you need to create a monochrome notification icon in res/drawable/ and reference it in the notification channel configuration. The notification icon must be a simple white-on-transparent design.
