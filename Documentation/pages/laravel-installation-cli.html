Livriko Laravel API (CLI)

This guide covers installing the Livriko Backend API using the command line. The CLI installation gives you full control over every step and is recommended for developers comfortable with the terminal. We cover both manual installation and the automated install.sh script.

Prerequisites
Before starting, ensure you have all prerequisites installed: PHP 8.2+, Composer 2.x, MySQL 8.0, Node.js 20+, and Git.

Quick Install

Livriko includes an automated installation script that handles the entire setup process. This is the fastest way to get started.

# Clone the repository
git clone https://github.com/HitechFacilitator/livriko.git
cd livriko/Taxido_laravel

# Run the automated installer
bash install.sh

The script will prompt you for:

  • Database name, username, and password
  • Application URL (e.g., http://localhost:8000)
  • Whether to run seeders with default data
Automated Setup
The install script handles: composer install, .env configuration, key:generate, migrate --seed, storage:link, and config:cache. It also verifies all PHP extensions are enabled.

What the Script Does

The automated installer performs the following operations in sequence:

StepCommandDescription
1composer installDownloads all PHP dependencies from Packagist
2cp .env.example .envCreates the environment configuration file
3php artisan key:generateGenerates the application encryption key
4php artisan migrate --seedCreates all database tables and populates default data
5php artisan storage:linkCreates the public storage symlink for file uploads
6php artisan config:cacheCaches the configuration for faster load times
7php artisan route:cacheCaches the route definitions for faster routing

Manual CLI Steps

If you prefer to run each step manually (or the automated script is not available), follow these steps one by one:

Step 1: Clone the Repository

git clone https://github.com/HitechFacilitator/livriko.git
cd livriko/Taxido_laravel

Step 2: Install Dependencies

composer install

Step 3: Configure Environment

cp .env.example .env
php artisan key:generate

Edit .env with your database credentials and application settings.

Step 4: Create Database

mysql -u root -p
CREATE DATABASE livriko_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;

Step 5: Run Migrations

php artisan migrate --seed

Step 6: Create Storage Link

php artisan storage:link

Step 7: Start Development Server

php artisan serve

The API will be available at http://localhost:8000.

Production .env Configuration

For production deployments, ensure your .env file includes the following settings:

# APPLICATION
APP_NAME=Livriko
APP_ENV=production
APP_DEBUG=false
APP_URL=https://yourdomain.com

# DATABASE
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=livriko_db
DB_USERNAME=livriko_user
DB_PASSWORD=your_secure_password

# CACHE & QUEUE (use Redis in production)
CACHE_DRIVER=redis
QUEUE_CONNECTION=redis
SESSION_DRIVER=redis
REDIS_HOST=127.0.0.1
REDIS_PORT=6379

# REVERB (WebSockets)
REVERB_APP_KEY=your-reverb-key
REVERB_APP_SECRET=your-reverb-secret
REVERB_APP_ID=your-reverb-app-id
REVERB_HOST=yourdomain.com
REVERB_PORT=443
REVERB_SCHEME=https
Never Commit .env
The .env file contains sensitive credentials and API keys. Never commit it to version control. The .env.example file is safe to commit as it contains only placeholder values.

Docker Installation

Livriko also supports Docker-based development. This is ideal for ensuring a consistent environment across your team and avoiding "works on my machine" issues.

# Clone the repository
git clone https://github.com/HitechFacilitator/livriko.git
cd livriko

# Start all services with Docker Compose
docker-compose up -d

# Install dependencies inside the app container
docker-compose exec app composer install
docker-compose exec app php artisan key:generate
docker-compose exec app php artisan migrate --seed
docker-compose exec app php artisan storage:link

# Access the application
# API: http://localhost:8000
# Admin: http://localhost:8000/admin
# phpMyAdmin: http://localhost:8080

Docker Services

The Docker Compose configuration includes the following services:

ServiceImagePortPurpose
appPHP 8.2 + Composer8000Laravel application server
mysqlMySQL 8.03306Database server
phpmyadminphpMyAdmin8080Database management interface
queuePHP 8.2—Laravel queue worker for background jobs
redisRedis 76379Caching and session storage
Docker Resources
Docker requires at least 4 GB of RAM allocated to Docker Desktop. If you encounter memory errors, increase the resource limits in Docker Desktop settings.

Verification

After installation, run these commands to verify everything is set up correctly:

# Check application key
php artisan key:show

# Verify database connection
php artisan db:show

# List all routes
php artisan route:list

# Check storage link
ls -la public/storage
Installation Complete
If all verification commands pass, the CLI installation is complete. Access the admin panel at http://localhost:8000/admin and log in with admin@livriko.com / password.
Change Default Password
Change the default admin password immediately after your first login. The default credentials are publicly documented and must never be used in a production environment.
