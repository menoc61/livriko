Livriko v1.0 · Based on Taxido

VPS Deployment — Nginx Server (LEMP) ⭐ Recommended

This is the recommended deployment method for Livriko. Nginx provides better performance, lower memory usage, and superior handling of concurrent connections compared to Apache. This guide covers the complete LEMP stack setup with PHP-FPM, MySQL, Redis, and Supervisor.

Why Nginx?
Nginx uses an event-driven architecture that handles thousands of simultaneous connections with minimal memory. For a ride-hailing platform with real-time WebSocket connections and high API traffic, Nginx is the optimal choice.

Automated Deployment

Livriko includes an automated install script that sets up the entire server stack. This is the fastest way to deploy:

# Download the install script
curl -O https://raw.githubusercontent.com/HitechFacilitator/livriko/main/install.sh

# Make it executable
chmod +x install.sh

# Run the script (requires root access)
sudo ./install.sh

The script will prompt you for:

  • Domain name
  • Database name, user, and password
  • Whether to install SSL (recommended)
Manual Setup
If you prefer to set up the server manually for full control over every step, follow the detailed instructions below.

Step 1: Update System

Update the system and install Nginx.

# Update system
sudo apt update && sudo apt upgrade -y

# Install Nginx
sudo apt install -y nginx

# Start and enable Nginx
sudo systemctl start nginx
sudo systemctl enable nginx

Step 2: Install PHP 8.2-FPM

Install PHP with FPM (FastCGI Process Manager) for Nginx integration.

# Add PHP repository
sudo add-apt-repository ppa:ondrej/php -y
sudo apt update

# Install PHP 8.2 and extensions
sudo apt install -y php8.2 php8.2-cli php8.2-common php8.2-fpm \
  php8.2-mysql php8.2-xml php8.2-mbstring php8.2-curl \
  php8.2-zip php8.2-gd php8.2-bcmath php8.2-redis \
  php8.2-intl php8.2-readline

# Start PHP-FPM
sudo systemctl start php8.2-fpm
sudo systemctl enable php8.2-fpm

Step 3: Install MySQL 8.0

Install and configure MySQL database server.

sudo apt install -y mysql-server

# Secure the installation
sudo mysql_secure_installation

# Create database and user
sudo mysql -u root -p

CREATE DATABASE livriko_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'livriko'@'localhost' IDENTIFIED BY 'your_secure_password';
GRANT ALL PRIVILEGES ON livriko_db.* TO 'livriko'@'localhost';
FLUSH PRIVILEGES;
EXIT;

Step 4: Install Redis

Install Redis for caching, sessions, and queue management.

sudo apt install -y redis-server

# Start and enable Redis
sudo systemctl start redis-server
sudo systemctl enable redis-server

# Test Redis connection
redis-cli ping
# Should return: PONG

Step 5: Install Composer and Node.js

Install the dependency managers.

# Install Composer
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer

# Install Node.js via NVM
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc
nvm install 20

Step 6: Deploy Livriko

Clone the repository, install dependencies, and configure the application.

# Clone the repository
cd /var/www
sudo git clone https://github.com/HitechFacilitator/livriko.git

# Set ownership
sudo chown -R www-data:www-data livriko
sudo chmod -R 755 livriko

# Navigate to Laravel directory
cd livriko/Taxido_laravel

# Install Composer dependencies
sudo -u www-data composer install --no-dev --optimize-autoloader

# Configure environment
sudo -u www-data cp .env.example .env
sudo -u www-data php artisan key:generate

Edit the .env file with your production values:

APP_NAME=Livriko
APP_ENV=production
APP_DEBUG=false
APP_URL=https://yourdomain.com

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=livriko_db
DB_USERNAME=livriko
DB_PASSWORD=your_secure_password

CACHE_DRIVER=redis
QUEUE_CONNECTION=redis
SESSION_DRIVER=redis
REDIS_HOST=127.0.0.1
REDIS_PORT=6379

REVERB_APP_KEY=your-reverb-key
REVERB_APP_SECRET=your-reverb-secret
REVERB_APP_ID=your-reverb-app-id
REVERB_HOST=yourdomain.com
REVERB_PORT=443
REVERB_SCHEME=https
# Run migrations and seeders
sudo -u www-data php artisan migrate --seed

# Create storage symlink
sudo -u www-data php artisan storage:link

# Optimize for production
sudo -u www-data php artisan config:cache
sudo -u www-data php artisan route:cache
sudo -u www-data php artisan view:cache

Step 7: Configure Nginx Server Block

Create the Nginx configuration for Livriko with WebSocket support.

sudo nano /etc/nginx/sites-available/livriko

Add the following configuration:

server {
    listen 80;
    listen [::]:80;
    server_name yourdomain.com www.yourdomain.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    listen [::]:443 ssl http2;
    server_name yourdomain.com www.yourdomain.com;

    root /var/www/livriko/Taxido_laravel/public;
    index index.php index.html;

    # Security Headers
    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";
    add_header X-XSS-Protection "1; mode=block";

    # Laravel URL Routing
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    # PHP-FPM Configuration
    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
        fastcgi_hide_header X-Powered-By;
    }

    # Static File Caching
    location ~* \.(jpg|jpeg|png|gif|ico|css|js|svg|woff|woff2|ttf|eot)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # Deny Hidden Files
    location ~ /\.(?!well-known) {
        deny all;
    }

    # WebSocket Proxy for Laravel Reverb
    location /reverb {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "Upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 86400;
    }
}
# Enable the site
sudo ln -s /etc/nginx/sites-available/livriko /etc/nginx/sites-enabled/

# Remove default site
sudo rm /etc/nginx/sites-enabled/default

# Test configuration
sudo nginx -t

# Restart Nginx
sudo systemctl restart nginx

Step 8: Set Permissions

Set the correct file permissions for the web server.

# Set ownership
sudo chown -R www-data:www-data /var/www/livriko

# Set directory permissions
sudo find /var/www/livriko -type d -exec chmod 755 {} \;

# Set file permissions
sudo find /var/www/livriko -type f -exec chmod 644 {} \;

# Allow web server write access
sudo chmod -R 775 /var/www/livriko/Taxido_laravel/storage
sudo chmod -R 775 /var/www/livriko/Taxido_laravel/bootstrap/cache

Step 9: Configure Supervisor

Set up Supervisor to manage the Laravel queue worker and Reverb WebSocket server as background processes.

Queue Worker

sudo nano /etc/supervisor/conf.d/livriko-worker.conf
[program:livriko-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/livriko/Taxido_laravel/artisan queue:work redis --sleep=3 --tries=3 --max-time=3600
autostart=true
autorestart=true
stopasgroup=true
killasgroup=true
user=www-data
numprocs=2
redirect_stderr=true
stdout_logfile=/var/www/livriko/Taxido_laravel/storage/logs/worker.log
stopwaitsecs=3600

Reverb WebSocket Server

sudo nano /etc/supervisor/conf.d/livriko-reverb.conf
[program:livriko-reverb]
process_name=%(program_name)s
command=php /var/www/livriko/Taxido_laravel/artisan reverb:start
autostart=true
autorestart=true
user=www-data
redirect_stderr=true
stdout_logfile=/var/www/livriko/Taxido_laravel/storage/logs/reverb.log
# Reload Supervisor
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start "livriko-worker:*"
sudo supervisorctl start livriko-reverb

Step 10: Install SSL with Certbot

Obtain a free SSL certificate from Let's Encrypt.

# Install Certbot
sudo apt install -y certbot python3-certbot-nginx

# Obtain SSL certificate
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com

# Verify auto-renewal
sudo certbot renew --dry-run

Step 11: Set Up Cron Job

Add the Laravel scheduler cron job.

sudo crontab -u www-data -e

# Add the following line:
* * * * * cd /var/www/livriko/Taxido_laravel && php artisan schedule:run >> /dev/null 2>&1

Step 12: Configure Firewall

Set up UFW firewall to allow only necessary traffic.

# Allow SSH
sudo ufw allow OpenSSH

# Allow HTTP and HTTPS
sudo ufw allow 'Nginx Full'

# Enable firewall
sudo ufw enable

# Check status
sudo ufw status

Verify Deployment

Run these commands to verify all services are running correctly.

# Check all service statuses
sudo systemctl status nginx
sudo systemctl status php8.2-fpm
sudo systemctl status mysql
sudo systemctl status redis-server

# Check Supervisor workers
sudo supervisorctl status

# Test the application
curl -I https://yourdomain.com
Deployment Complete
Access https://yourdomain.com/admin and log in with admin@livriko.com / password to verify the deployment. Remember to change the default password immediately.
