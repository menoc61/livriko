Environment URL

Configure the API endpoint URLs that connect your Livriko mobile apps to the backend. This page covers development vs. production environments, Firebase URLs, and debugging tips for connection issues.

Environment Overview

The Livriko apps support two primary environments:

Environment API URL Usage
Development http://192.168.x.x/livriko/public Local development and testing
Production https://livriko.fr/api Live production deployment
Warning

Never use http://localhost or http://127.0.0.1 when running on a physical device or emulator. The emulator and device use a different network context. Always use your machine's actual IP address for development.

User App Configuration

API URL

Edit the config file to set your backend API endpoint:

File: Taxido_user/src/config/config.tsx

// Taxido_user/src/config/config.tsx
export const URL = 'https://livriko.fr';

For local development, use your machine's local IP address:

// Local development
export const URL = 'http://192.168.1.100/livriko/public';

Google Maps API Key

Edit the context file to set your Google Maps key:

File: Taxido_user/src/context/index.tsx

// Taxido_user/src/context/index.tsx
export const GOOGLE_MAPS_API_KEY = 'YOUR_GOOGLE_MAPS_API_KEY';

Driver App Configuration

API URL

Edit the same config file in the Driver App directory:

File: Taxido_driver/src/config/config.tsx

// Taxido_driver/src/config/config.tsx
export const URL = 'https://livriko.fr';

Google Maps API Key

Edit the context file in the Driver App directory:

File: Taxido_driver/src/context/index.tsx

// Taxido_driver/src/context/index.tsx
export const GOOGLE_MAPS_API_KEY = 'YOUR_GOOGLE_MAPS_API_KEY';

Environment Variables Summary

Variable File Location Purpose
URL src/config/config.tsx Backend API base URL for all HTTP requests
GOOGLE_MAPS_API_KEY src/context/index.tsx Google Maps API key for maps, geocoding, and directions

Firebase URL

If you are using Firebase for real-time data (e.g., driver location tracking), you also need to configure the Firebase Realtime Database URL:

File: Taxido_user/src/config/config.tsx

// Firebase Realtime Database URL
export const FIREBASE_URL = 'https://your-project.firebaseio.com';

Find this URL in the Firebase Console under Project Settings → General → Realtime Database URL.

Debugging Connection Issues

If the app cannot reach the backend, use these debugging steps:

Verify the Backend is Running

# From your development machine
curl -I https://livriko.fr/api/v1/ping
# Should return HTTP 200

Check Network Accessibility

# From the emulator/device terminal
adb shell ping -c 4 192.168.1.100
# Should show successful pings

Test API Endpoint Directly

# Test the API endpoint from the command line
curl -X GET https://livriko.fr/api/v1/vehicle-types \
  -H "Accept: application/json" \
  -H "Content-Type: application/json"
Tip

Use the React Native Debugger or Flipper to inspect network requests in real-time. Enable network logging to see all API calls made by the app.

Common Connection Errors

Error Cause Solution
Network request failed Incorrect API URL or backend not running Verify the URL and ensure the backend is accessible
SSL handshake failed Invalid SSL certificate Ensure the backend uses a valid SSL certificate from a trusted CA
Connection refused Backend server is not running Start the Laravel backend server
Timeout Slow network or server overload Check network latency and server response times

Full Rebuild Required

Important

After changing the API URL or Google Maps API key, you must perform a full rebuild. Hot reloading will not pick up changes to these constants. Stop the Metro bundler, clean the build, and rebuild.

# Stop Metro bundler (Ctrl+C), then:
cd Taxido_user

# Android
cd android && ./gradlew clean && cd ..
npm run android

# iOS
cd ios && pod install && cd ..
npm run ios
