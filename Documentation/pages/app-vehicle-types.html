Vehicle Types

Vehicle types define the different categories of vehicles available for ride booking in Livriko. Each vehicle type has its own pricing, capacity, and icon displayed in the user app.

How Vehicle Types Work

Vehicle types are configured in the admin panel and pushed to the mobile apps via the API. When a user requests a ride, the app fetches available vehicle types for their current zone and displays them as selectable options. Each type shows its name, capacity, estimated fare, and arrival time.

Admin-Configured Types

Livriko comes with pre-configured vehicle types that you can customize. Each type has the following properties set in the admin panel:

Property Description Example
Name Display name shown to users in the app Sedan, SUV, Luxury
Capacity Maximum number of passengers 2, 4, 6
Description Brief description of the vehicle type "Affordable everyday rides"
Image Vehicle icon or photo displayed in the app Uploaded PNG/SVG
Status Enable or disable this vehicle type Active / Inactive
Sort Order Display order in the vehicle selection screen 1, 2, 3...

Vehicle Type Capacity Description Use Case

Selection Screen

After entering pickup and destination, the User app displays a vehicle selection screen. Each vehicle type is shown as a card with:

  • Vehicle image/icon
  • Type name and passenger capacity
  • Estimated fare for the trip
  • Estimated time of arrival (ETA) for the nearest driver of that type
  • A "Choose" or "Book" button to confirm selection

The vehicle selection screen only shows types that are enabled in the admin panel, have available drivers nearby, and are assigned to the user's current zone.

Price Estimation

Vehicle type pricing is configured per zone in the Vehicle Zone Pricing section. The fare estimate is calculated using:

Estimated Fare = Base Fare + (Per KM × Distance) + (Per Minute × Duration)
Pricing Field Description Example
Base Fare Fixed amount charged at the start of a ride $2.50
Per KM Charge per kilometer traveled $0.75/km
Per Minute Charge per minute of ride time $0.15/min
Minimum Fare Lowest possible fare for a ride $5.00
Maximum Fare Ceiling for fare calculation (optional) $50.00
Cancellation Fee Fee charged when a ride is cancelled after acceptance $3.00

Creating a New Vehicle Type

Open Admin Panel

Log in to the admin panel and navigate to Vehicle Types from the sidebar.

Click Add New

Click the Add New button to open the vehicle type creation form.

Fill in Details

Enter the name, capacity, description, upload an image, and set the status to Active.

Configure Pricing

Go to Vehicle Zone Pricing and set the base fare, per-km rate, and per-minute rate for each zone where this vehicle type should be available.

Save and Test

Click Save. Open the User app and verify the new vehicle type appears in the selection screen.

Zone Assignment Required

Vehicle types must be assigned to zones in the Vehicle Zone Pricing section for them to appear as available options to users. A vehicle type without zone assignment will not show up in the app.

Driver Vehicle Matching

Drivers must have their vehicle type set in their profile. The app only matches riders with drivers who drive the selected vehicle type. Ensure your driver registration flow collects vehicle type information and that drivers update their vehicle details when they change vehicles.

Optimize Your Fleet Mix

Analyze ride request data in the admin panel to understand which vehicle types are most popular in each zone. Adjust your fleet composition and pricing accordingly. For example, if SUV requests frequently result in long wait times, encourage more SUV drivers to go online in those zones.
