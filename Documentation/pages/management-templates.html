Notification Templates

Customize email, SMS, and push notification templates for every platform event — ensure consistent, professional messaging across all channels.

Overview

Notification templates define the content and format of automated messages sent to riders and drivers. Livriko uses templates for three communication channels: Email, SMS, and Push Notification. Each template is triggered by a specific platform event and can be customized to match your brand voice.

Templates use variables (placeholders) that are dynamically replaced with real data at the time of sending. For example, {{user_name}} is replaced with the recipient's actual name.

Multi-Channel Support

Most events trigger notifications across multiple channels. For example, a ride completion sends a push notification to the rider, an email receipt, and an SMS confirmation. Each channel's template can be edited independently.

Template Types

Email

Rich HTML email templates for detailed communications. Supports images, links, and formatted text. Ideal for receipts, welcome emails, and promotional campaigns.

SMS

Plain text SMS templates for concise, time-sensitive messages. Used for OTPs, ride confirmations, and critical alerts. Character count is limited to 160 per segment.

Push Notification

Short-form push notification templates delivered via FCM. Displayed on the device lock screen and notification center. Used for real-time ride updates and promotions.

Template Variables

Variables are placeholders in template content that are dynamically replaced with real data when the notification is sent. Use double curly braces {{variable_name}} to insert variables.

Variable Description Available In
{{user_name}} The recipient's full name. All events
{{user_email}} The recipient's email address. Registration, Password Reset
{{ride_id}} The unique ride identifier. Ride events
{{driver_name}} The assigned driver's name. Driver Assigned, Ride Completed
{{driver_phone}} The assigned driver's phone number. Driver Assigned
{{pickup_location}} The ride pickup address. Ride Booking, Driver Assigned
{{dropoff_location}} The ride drop-off address. Ride Booking, Ride Completed
{{ride_fare}} The total fare amount for the ride. Ride Completed, Payment Processed
{{vehicle_type}} The vehicle type used for the ride. Ride events
{{amount}} A generic amount field (used for wallet credits, refunds, etc.). Payment, Wallet events
{{otp_code}} The one-time password for ride verification or password reset. Password Reset, Ride Verification
{{promo_code}} The promotional discount code. Promotional
{{app_name}} The platform name as configured in App Settings. All events
Variable Validation

Always test your templates before saving. Invalid or misspelled variables will appear as raw text (e.g., {{user_nmae}}) in the notification, which looks unprofessional and confuses users.

Editing a Template

1

Navigate to Notification Templates

Go to Livriko Management → Notification Templates. You will see a list of all available templates grouped by event.

2

Select a Template

Click on the event you want to customize. You will see tabs for each channel (Email, SMS, Push) that can be edited independently.

3

Edit the Content

Modify the subject line (for email), message body, and any other content fields. Insert variables using {{variable_name}} syntax where dynamic data should appear.

4

Preview and Save

Use the preview function to see how the notification will look with sample data. When satisfied, click Save to apply the changes.

Default Templates

Livriko ships with pre-configured templates for every event. These defaults are professionally written and follow best practices for clarity and tone. You can use them as-is or customize them to match your brand.

Reset to Defaults

If you heavily customize a template and want to revert, most templates include a Reset to Default option. This restores the original Livriko-provided content while preserving your other template settings.

Multi-Language Template Support

If your platform supports multiple languages through Platform Languages, each template can have language-specific variants. When a notification is sent, the system automatically selects the template variant matching the recipient's preferred language.

  • Language Variants — Create separate template content for each enabled language (e.g., English, French, Arabic).
  • Fallback — If a template variant is missing for a language, the system falls back to the default language (typically English).
  • RTL Support — Email and push templates support right-to-left text direction for languages like Arabic and Hebrew.
Localization Tip

When creating multi-language templates, avoid hardcoding text outside of variables. Keep all user-facing text in the template content so translators can localize it without touching the code.
