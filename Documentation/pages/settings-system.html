System Tools

The System Tools section provides utilities for managing and maintaining your Livriko installation. Use these tools carefully, especially in production environments.

Cache Management

Livriko caches configuration, routes, views, and events for performance. When you make changes, clear the relevant cache:

Tool Description Command
Clear Config Resets cached configuration files php artisan config:clear
Clear Cache Clears application cache php artisan cache:clear
Clear Routes Resets cached route definitions php artisan route:clear
Clear Views Recompiles fresh view templates php artisan view:clear
Clear Events Resets cached event listeners php artisan event:clear

Run all cache-clearing commands at once:

php artisan config:clear
php artisan cache:clear
php artisan route:clear
php artisan view:clear
php artisan event:clear
Warning

Do not run cache-clearing commands on a live production server during peak hours. These commands can cause temporary performance degradation as caches are rebuilt. Schedule maintenance windows for these operations.

Queue Management

Livriko uses Laravel queues for background jobs like sending notifications and processing payments.

Start Queue Worker

# Start the queue worker
php artisan queue:work --sleep=3 --tries=3

# Start with specific connection
php artisan queue:work redis --sleep=3 --tries=3

# Start with maximum runtime (auto-restart after 3600 seconds)
php artisan queue:work --max-time=3600

Restart Queue Workers

# Gracefully restart all queue workers
php artisan queue:restart

# Check queue status
php artisan queue:status

Process Failed Jobs

# Retry a specific failed job
php artisan queue:retry {job-id}

# Retry all failed jobs
php artisan queue:retry all

# Clear failed jobs
php artisan queue:flush
Production Tip

For production environments, use a process manager like Supervisor to keep queue workers running. Create a Supervisor configuration file to automatically restart workers if they fail.

Log Viewer

Laravel logs are stored in the storage/logs/ directory. Use these commands to view and manage logs:

# View the last 100 lines of the log file
tail -100 storage/logs/laravel.log

# Watch the log file in real-time
tail -f storage/logs/laravel.log

# Search for errors in the log
grep -i "error" storage/logs/laravel.log

# View logs for a specific date
grep "2024-06-20" storage/logs/laravel.log

Database Maintenance

Run Migrations

# Run all pending migrations
php artisan migrate

# Run migrations without confirmation
php artisan migrate --force

# Rollback the last migration batch
php artisan migrate:rollback

# Rollback and re-run all migrations
php artisan migrate:refresh

Database Backup

# Create a database dump
php artisan db:dump

# Or use mysqldump directly
mysqldump -u root -p livriko > backup_$(date +%Y%m%d_%H%M%S).sql

# Restore from backup
mysql -u root -p livriko < backup_file.sql

Database Seeding

# Seed the database with default data
php artisan db:seed

# Seed specific table
php artisan db:seed --class=VehicleTypeSeeder

PHP Information

# Check PHP version and extensions
php --version

# View PHP configuration
php --ini

# Check if a specific extension is loaded
php -m | grep -i "extension-name"

Scheduler (Crontab)

The scheduler handles recurring tasks. Add this to your crontab to run the scheduler every minute:

# Edit crontab
crontab -e

# Add the following line
* * * * * cd /path-to-your-project && php artisan schedule:run >> /dev/null 2>&1

The scheduler runs the following tasks automatically:

Task Frequency Description
Clean expired sessions Every hour Removes expired user sessions from the database
Generate reports Daily at midnight Generates daily analytics and financial reports
Send scheduled notifications Every 5 minutes Delivers queued notifications to users
Clean old logs Weekly Archives and removes old log files

When to Use Each Tool

Scenario Tool(s) to Use
Changed .env file php artisan config:clear
Added new routes php artisan route:clear
Modified blade templates php artisan view:clear
Updated database schema php artisan migrate
Emails not sending Check queue worker, restart with php artisan queue:work
Performance issues Clear all caches, check queue worker status
After code deployment Run all cache-clearing commands + composer dump-autoload

Automation Tips

  • Use Supervisor for queue workers — Automatically restarts failed workers and manages process lifecycle
  • Set up cron for the scheduler — Ensures recurring tasks run on time
  • Implement deployment scripts — Automate cache clearing, migrations, and composer install after each deployment
  • Monitor logs — Use tools like Laravel Telescope or Sentry for real-time error monitoring
  • Automate backups — Schedule daily database backups using cron or your hosting provider's backup tools
Example Deployment Script
#!/bin/bash
# deploy.sh — Run after pulling new code

php artisan down
git pull origin main
composer install --no-dev --optimize-autoloader
npm install && npm run build
php artisan migrate --force
php artisan config:clear
php artisan cache:clear
php artisan route:clear
php artisan view:clear
php artisan event:clear
php artisan up
