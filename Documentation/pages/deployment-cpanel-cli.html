cPanel Server Deployment (CLI)

This guide covers deploying the Livriko Backend API to shared hosting via SSH command line. This method is faster than the GUI approach and gives you more control over the installation process.

SSH Access Required
SSH access must be enabled on your hosting account. Contact your hosting provider if you do not have SSH access. Most shared hosting plans include SSH by default.

Step 1: SSH Access Setup

Open your terminal and connect to your hosting server using SSH.

# Connect using your cPanel credentials
ssh username@yourdomain.com

# Or use the port specified by your hosting provider
ssh -p 2222 username@yourdomain.com

# If using SSH key authentication
ssh -i ~/.ssh/id_rsa username@yourdomain.com
Finding SSH Credentials
Your SSH credentials are the same as your cPanel login. You can find the SSH port in cPanel under Security → SSH Access.

Step 2: Navigate to Document Root

Navigate to the public_html directory (or your domain's document root).

cd ~/public_html

Step 3: Clone Repository

Clone the Livriko repository from GitHub.

# Clone the repository
git clone https://github.com/HitechFacilitator/livriko.git

# Navigate to the Laravel backend
cd livriko/Taxido_laravel

Step 4: Install Dependencies

Install PHP dependencies using Composer. Use the --no-dev flag for production to skip development packages.

# Install dependencies (production, no dev)
composer install --no-dev --optimize-autoloader
Production Flags
Always use --no-dev for production deployments to avoid installing test and development dependencies. Use --optimize-autoloader to improve autoloading performance.

Step 5: Configure Environment

Create and configure the .env file with your production settings.

# Copy the example environment file
cp .env.example .env

# Generate the application key
php artisan key:generate

# Edit the .env file with your production settings
nano .env

Update the .env file with your cPanel database credentials:

APP_NAME=Livriko
APP_ENV=production
APP_KEY=base64:YOUR_GENERATED_KEY
APP_DEBUG=false
APP_URL=https://yourdomain.com/livriko/public

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=yourusername_livriko_db
DB_USERNAME=yourusername_dbuser
DB_PASSWORD=your_database_password

CACHE_DRIVER=file
QUEUE_CONNECTION=sync
SESSION_DRIVER=file

Step 6: Run Migrations

Run the database migrations and seeders to create all tables and populate default data.

# Run all migrations and seeders
php artisan migrate --seed
Default Data
The seeders populate the database with admin accounts, vehicle types, zones, platform settings, and sample data. This is essential for the platform to function correctly.

Step 7: Set Permissions

Set the correct file permissions for Laravel to function properly on shared hosting.

# Set directory permissions
chmod -R 775 storage/
chmod -R 775 bootstrap/cache/

# Ensure the web server can write to storage
chown -R $(whoami):$(whoami) storage/ bootstrap/cache/

Step 8: Create Storage Symlink

Create the storage symlink so uploaded files are accessible via the web.

php artisan storage:link
Symlink Issues?
If symlink creation fails, you may need to ask your hosting provider to enable symlinks, or manually create the link through cPanel File Manager by creating a symlink from public/storage to ../storage/app/public.

Step 9: Configure Cron Job

Laravel requires a cron job for scheduled tasks. Set it up in cPanel or via crontab.

Option A: Via cPanel Cron Jobs interface:

  1. Open Cron Jobs in cPanel
  2. Set the cron schedule to run every minute: * * * * *
  3. Add the following command
cd ~/public_html/livriko/Taxido_laravel && php artisan schedule:run >> /dev/null 2>&1

Option B: Via SSH crontab:

crontab -e

# Add this line:
* * * * * cd ~/public_html/livriko/Taxido_laravel && php artisan schedule:run >> /dev/null 2>&1

Step 10: Configure .htaccess

Laravel includes an .htaccess file in the public directory that handles URL rewriting. Ensure it exists and is properly configured:

# Verify .htaccess exists
ls -la public/.htaccess

# If missing, create it
cat > public/.htaccess << 'HTACCESS'
<IfModule mod_rewrite.c>
    <IfModule mod_negotiation.c>
        Options -MultiViews -Indexes
    </IfModule>

    RewriteEngine On

    # Handle Front Controller...
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteRule ^ index.php [L]
</IfModule>
HTACCESS
Deployment Complete
Access https://yourdomain.com/admin and log in with admin@livriko.com / password to verify the deployment. Remember to change the default password immediately.
