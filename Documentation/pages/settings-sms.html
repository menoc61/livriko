SMS Gateways

SMS gateways power OTP verification, ride notifications, and transactional messages in Livriko. Configure a reliable provider to ensure riders and drivers receive messages without delay.

Supported SMS Gateways

Livriko ships with multiple SMS provider integrations. Only one can be active at a time.

Gateway Status Global Coverage Best For
Twilio Enabled 180+ countries High reliability, global reach
Nexmo (Vonage) Enabled 200+ countries Cost-effective global SMS
Africastalking Disabled Africa East & West African markets
Bulksms Disabled South Africa & Africa South African operations
Only one gateway active at a time

When you enable a new SMS gateway, the previously active one is automatically disabled. This prevents duplicate messages and conflicting configurations.

Twilio Configuration

Twilio is the most popular SMS gateway for ride-hailing platforms due to its reliability and global coverage.

Step-by-Step Twilio Setup

Create a Twilio account

Visit twilio.com/try-twilio and sign up for a free trial account. You will receive a free trial balance to test SMS sending.

Get your Account SID and Auth Token

After logging into the Twilio Console, you will see your Account SID (starts with AC) and Auth Token on the dashboard. Click the eye icon to reveal the Auth Token.

Purchase a Twilio phone number

Go to Phone Numbers → Buy a Number in the Twilio Console. Choose a number in your target country. Ensure the number has SMS capability enabled. This number will appear as the sender of your SMS messages.

Configure in Livriko Admin

Navigate to Settings → SMS Gateways. Select Twilio and click Configure.

Twilio Field Description Example
Account SID Unique identifier for your Twilio account AC1234567890abcdef...
Auth Token Secret authentication token for API requests your_auth_token_here
From Number Twilio phone number used as the SMS sender +14155551234 
# Twilio Configuration in .env
SMS_GATEWAY=twilio
TWILIO_SID=YOUR_TWILIO_SECRET_KEY
TWILIO_TOKEN=your_auth_token_here
TWILIO_FROM=+xxxxxxxxxxx

Test SMS delivery

Enter your phone number in the test field and click Send Test SMS. You should receive a message within 30 seconds. If not, check your Twilio console for delivery logs.

Verify phone number format

Ensure all phone numbers in your database include the country code prefix (e.g., +1 for US, +212 for Morocco). Twilio requires E.164 formatted numbers.

Twilio trial accounts

Twilio trial accounts can only send SMS to verified phone numbers. Add test numbers in Phone Numbers → Verified Caller IDs during development. Upgrade to a paid account for production use.

Nexmo (Vonage) Configuration

Nexmo, now part of Vonage, is a cost-effective SMS gateway with excellent global reach.

Create a Vonage account

Visit dashboard.nexmo.com/sign-up and create an account. Vonage provides free test credits for new accounts.

Get API Key and Secret

In the Vonage Dashboard, your API Key and API Secret are displayed on the landing page. Copy both values.

Buy a virtual number (optional)

Go to Numbers → Buy Numbers and purchase a virtual number for your region. If you don't buy a number, Vonage uses a shared short code, which may not be available in all countries.

Configure in Livriko Admin

Navigate to Settings → SMS Gateways. Select Nexmo and click Configure. Enter your API Key, API Secret, and Sender Number (if purchased).

Nexmo Field Description Example
API Key Your Nexmo/Vonage API key abc12345
API Secret Secret key for API authentication AbCdEfGhIjKlMnOpQrSt
Sender Name Sender ID or virtual number (max 11 characters for sender ID) Livriko or +14155551234 
# Nexmo/Vonage Configuration in .env
SMS_GATEWAY=nexmo
NEXMO_KEY=abc12345
NEXMO_SECRET=AbCdEfGhIjKlMnOpQrSt
NEXMO_SENDER=Livriko

SMS Template Management

Customize the SMS messages sent to riders and drivers for various events.

Livriko sends SMS messages for the following events:

Event Recipient Default Template
OTP Verification Rider / Driver Your Livriko verification code is {code}. Valid for 5 minutes.
Ride Accepted Rider Your ride has been accepted by {driver_name}. Vehicle: {vehicle}. ETA: {eta}.
Ride Completed Rider Your ride is complete. Total fare: {amount}. Thank you for riding with Livriko!
Ride Cancelled Rider / Driver Your ride has been cancelled. Reason: {reason}.
Driver Arriving Rider Your driver {driver_name} is arriving in {minutes} minutes.
Wallet Top-Up Rider / Driver Your wallet has been topped up with {amount}. New balance: {balance}.

To edit SMS templates, go to Settings → Notification Templates in the admin panel. Each template supports placeholder variables enclosed in {curly braces}.

SMS length limits

Standard SMS messages are limited to 160 characters. Messages longer than this are split into multiple SMS segments, which increases costs. Keep templates concise and only include essential information.

Verification SMS Setup

OTP (One-Time Password) verification is the primary authentication method for Livriko users.

How OTP Verification Works

User enters phone number

The rider or driver enters their phone number in the app's login/register screen.

Platform generates OTP

Livriko generates a 6-digit code and stores it in the database with a 5-minute expiration timer.

SMS is sent via gateway

The OTP is sent to the user's phone number via the configured SMS gateway (Twilio, Nexmo, etc.).

User enters OTP

The user enters the 6-digit code in the app. The platform validates the code and the expiration time.

OTP Configuration

You can configure the following OTP settings in the admin panel under Settings → General:

  • OTP Length: Number of digits in the verification code (default: 6).
  • OTP Expiry: Time in minutes before the code expires (default: 5).
  • Max Attempts: Number of incorrect attempts allowed before the code is invalidated (default: 5).
  • Resend Delay: Minimum seconds between OTP resend requests (default: 60).

Testing SMS Delivery

Always test your SMS gateway configuration before going live.

Send a test SMS from Admin

Go to Settings → SMS Gateways. Enter your phone number and click Send Test SMS. Verify you receive the message within 30 seconds.

Test the full registration flow

Create a test rider account using your own phone number. Verify that the OTP arrives, the code works, and the account is created successfully.

Check gateway logs

If messages are not delivered, check the SMS gateway's dashboard for delivery logs. Common issues include incorrect phone number format, insufficient balance, or blocked numbers.

Monitor delivery rates

In production, monitor SMS delivery rates through the gateway dashboard. A delivery rate below 95% indicates a configuration or provider issue.

SMS delivery checklist

✓ Phone numbers include country code prefix • ✓ Gateway account has sufficient balance • ✓ Sender number/ID is registered and approved • ✓ Test SMS received successfully • ✓ OTP flow tested end-to-end
