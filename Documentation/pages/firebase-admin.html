Connect Firebase with Admin

To enable push notifications and server-side Firebase operations from the Laravel admin panel, you need to connect your Firebase project using a Service Account.

Why Connect Firebase to Laravel?

The Livriko admin panel needs server-side access to Firebase for:

  • Push Notifications — Send FCM notifications to riders and drivers
  • User Management — Create, update, and delete Firebase Auth users
  • Firestore Operations — Read and write data to Firestore collections
  • Cloud Functions — Trigger serverless functions from the admin

Step 1: Generate Service Account Credentials

Open Firebase Console

Go to Firebase Console → Project Settings (gear icon in the top-left).

Navigate to Service Accounts

Click the "Service accounts" tab in the settings page.

Generate New Private Key

Click "Generate New Private Key" at the bottom of the page. Confirm by clicking "Generate key" in the dialog.

Download the JSON File

A JSON file will be downloaded to your computer. This file contains your Firebase service account credentials.

Security Warning

The downloaded JSON file contains sensitive private keys. Never commit it to Git or share it publicly. Add it to your .gitignore file immediately.

Step 2: Place Credentials in Laravel

Create a directory for Firebase credentials and move the downloaded file:

# Create the directory
mkdir -p storage/app/firebase

# Move the downloaded JSON file (rename for clarity)
mv ~/Downloads/your-project-firebase-adminsdk-xxxxx.json \
   storage/app/firebase/firebase.json

Add the file to your .gitignore:

# .gitignore
storage/app/firebase/firebase.json

Step 3: Update Environment Configuration

Add the Firebase credentials path to your .env file:

# Firebase configuration
FIREBASE_CREDENTIALS=storage/app/firebase/firebase.json

# Firebase project settings
FIREBASE_PROJECT_ID=your-firebase-project-id
FIREBASE_DATABASE_URL=https://your-project.firebaseio.com

# Cloud Messaging
FCM_SERVER_KEY=your-firebase-server-key
FCM_SENDER_ID=your-sender-id
Note

Ensure the path in FIREBASE_CREDENTIALS points to the correct location of your firebase.json credentials file relative to the Laravel project root.

Step 4: Firebase Admin SDK Initialization

Livriko initializes the Firebase Admin SDK automatically using the credentials from your .env file. The SDK is configured in the service provider:

// In your Laravel application (handled by Livriko automatically):
use Kreait\Firebase\Factory;

$factory = (new Factory)
    ->withServiceAccount(
        storage_path('app/firebase/firebase.json')
    )
    ->withProjectId(config('services.firebase.project_id'));

$firebase = $factory->create();

// Get instances
$auth = $firebase->getAuth();          // Firebase Authentication
$firestore = $firebase->getFirestore(); // Cloud Firestore
$messaging = $firebase->getMessaging(); // Cloud Messaging

Step 5: Server Key for Push Notifications

The Server Key is used for sending push notifications via FCM. To find it:

Open Firebase Console

Go to Firebase Console → Project Settings → Cloud Messaging tab.

Copy the Server Key

Copy the Server key value. If you don't see it, you may need to use the Cloud Messaging API (Legacy) or use the HTTP v1 API with an OAuth 2.0 token.

Configure in Admin Panel

In the Livriko admin panel, navigate to Settings → Firebase and paste the server key in the FCM Server Key field.

Sender ID Configuration

The Sender ID is a unique number that identifies your Firebase project. It is used by mobile apps to register FCM tokens.

# Find your Sender ID in Firebase Console
# Project Settings → Cloud Messaging → Sender ID

# Add to .env
FIREBASE_SENDER_ID=123456789000

Testing the Connection

After configuring the credentials, verify the connection is working:

# Open Laravel Tinker
php artisan tinker

# Check Firebase credentials are loaded
config('services.firebase.credentials')

# Test Firestore connection
$firestore = app('firebase.firestore');
$collection = $firestore->collection('riders');
echo "Firestore connection OK. Collection count: " .
     count($collection->documents());

# Test Auth connection
$auth = app('firebase.auth');
$users = $auth->listUsers(100);
echo "Auth connection OK. User count: " . count($users);

Troubleshooting Connection Issues

Issue Cause Fix
"No API key found" Missing FIREBASE_CREDENTIALS in .env Ensure the environment variable is set and points to the correct file
"Invalid credentials" Corrupted or wrong JSON file Re-download the credentials from Firebase Console
"Permission denied" Service Account lacks required roles Ensure the service account has the "Firebase Admin SDK Administrator Service Agent" role
"Project not found" Wrong project ID in .env Verify FIREBASE_PROJECT_ID matches your Firebase project
