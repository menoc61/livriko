Android Setup

This guide walks you through setting up your development environment for building and running the Livriko User App and Driver App on Android devices and emulators.

Install Android Studio

Download and install the latest stable version of Android Studio from the official website:

https://developer.android.com/studio

During installation, ensure the following components are selected in the setup wizard:

  • Android SDK
  • Android SDK Platform-Tools
  • Android Virtual Device (AVD)
  • Android SDK Build-Tools

SDK Manager Setup

After installing Android Studio, open the SDK Manager (Tools → SDK Manager) and install the following components:

Component Version Purpose
Android SDK Platform 36 Target API level for building
Android SDK Build-Tools 36 Required for compiling native code
Android SDK Platform-Tools Latest ADB and debugging utilities
NDK (Side by Side) 27.1 Native Development Kit for C++ modules
Note

You can also install these via the command line using sdkmanager:

sdkmanager "platforms;android-36" "build-tools;36.0.0" "platform-tools" "ndk;27.1.12297006"

Environment Variables

Set the following environment variables so that React Native can locate your Android SDK and tools:

ANDROID_HOME

This variable points to your Android SDK installation directory:

# macOS/Linux — add to ~/.zshrc or ~/.bashrc
export ANDROID_HOME=$HOME/Library/Android/sdk
# or on Linux:
export ANDROID_HOME=$HOME/Android/Sdk

# Windows (PowerShell)
[System.Environment]::SetEnvironmentVariable(
  "ANDROID_HOME",
  "C:\Users\YourUser\AppData\Local\Android\Sdk",
  "User"
)

JAVA_HOME

This variable points to your JDK 17 installation directory:

# macOS/Linux — add to ~/.zshrc or ~/.bashrc
export JAVA_HOME=$(/usr/libexec/java_home -v 17)
# or on Linux:
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk

# Windows (PowerShell)
[System.Environment]::SetEnvironmentVariable(
  "JAVA_HOME",
  "C:\Program Files\Eclipse Adoptium\jdk-17",
  "User"
)

PATH

Add the SDK tools to your system PATH:

# macOS/Linux — add to ~/.zshrc or ~/.bashrc
export PATH=$PATH:$ANDROID_HOME/emulator
export PATH=$PATH:$ANDROID_HOME/platform-tools
export PATH=$PATH:$ANDROID_HOME/tools
export PATH=$PATH:$ANDROID_HOME/tools/bin

After setting these variables, reload your shell configuration:

# For zsh
source ~/.zshrc

# For bash
source ~/.bashrc

Java JDK 17

The Livriko apps require JDK 17 for Android builds. Install it using your preferred package manager:

macOS (Homebrew)

brew install openjdk@17
sudo ln -sfn $(brew --prefix openjdk@17)/libexec/openjdk.jdk \
  /Library/Java/JavaVirtualMachines/openjdk-17.jdk

Linux (APT)

sudo apt update
sudo apt install openjdk-17-jdk
java -version  # Should show JDK 17

Windows

Download the JDK 17 installer from Adoptium and follow the installation wizard. Ensure JAVA_HOME is set after installation.

Create a Virtual Device

To run the app on an emulator, create an Android Virtual Device (AVD):

  1. Open Android Studio
  2. Go to Tools → Device Manager
  3. Click Create Device
  4. Select a device definition (e.g., Pixel 7) and click Next
  5. Select a system image with API 34 or higher and click Next
  6. Configure the AVD name and settings, then click Finish
  7. Click the Play button to start the emulator
Warning

Ensure that Hardware Acceleration (HAXM on Intel or Hypervisor Framework on Apple Silicon) is enabled for smooth emulator performance. Without it, the emulator will be extremely slow.

Gradle Configuration

The Livriko Android projects use Gradle 8.9 as the build automation tool. If you encounter build issues, check the following in android/gradle/wrapper/gradle-wrapper.properties:

# android/gradle/wrapper/gradle-wrapper.properties
distributionUrl=https\://services.gradle.org/distributions/gradle-8.9-all.zip

For memory-constrained machines, increase the Gradle JVM memory in android/gradle.properties:

# android/gradle.properties
org.gradle.jvmargs=-Xmx4096m -XX:MaxMetaspaceSize=512m
org.gradle.daemon=true
org.gradle.parallel=true

Signing Keys

For release builds, you need to configure a signing key. Create a keystore file:

keytool -genkeypair -v -storetype PKCS12 \
  -keystore my-release-key.keystore \
  -alias my-key-alias \
  -keyalg RSA -keysize 2048 \
  -validity 10000

Then configure it in android/app/build.gradle:

signingConfigs {
    release {
        storeFile file('my-release-key.keystore')
        storePassword System.getenv("KEYSTORE_PASSWORD") ?: ""
        keyAlias 'my-key-alias'
        keyPassword System.getenv("KEY_PASSWORD") ?: ""
    }
}
Important

Never commit your keystore file or passwords to version control. Add *.keystore to your .gitignore file and store passwords in environment variables or a secure vault.

Verify Your Setup

Run these commands to verify everything is configured correctly:

# Check Android SDK path
echo $ANDROID_HOME

# Check ADB
adb --version

# Check Java version
java -version  # Should show JDK 17

# Check connected devices / emulators
adb devices

# Check Gradle
cd Taxido_user/android && ./gradlew --version
All checks passed?

If all the commands above return valid output, your Android development environment is ready. You can now proceed to install and run the Livriko apps.
