Landing Page

The landing page is the public-facing website that users see before downloading the app. Customize it to match your brand and provide essential information about your service.

Configuration Fields

Field Description
App Name Your platform name displayed in the header and throughout the page
Tagline A short slogan or tagline (e.g., "Your Ride, Your Way")
Description Brief description of your service for SEO and user information
Logo Your brand logo displayed in the header (recommended: 200x50px PNG)
Favicon Browser tab icon (recommended: 32x32px ICO or PNG)
Primary Color Main brand color used for buttons and accents
Secondary Color Complementary color for secondary elements

Banner / Slider Management

The hero banner is the first thing visitors see. Manage slides to create an engaging first impression:

Add a Slide

Click "Add Slide" in the banner management section. Upload a high-quality image (recommended: 1920x1080px) and enter the slide title and description.

Configure CTA Buttons

Each slide can have a call-to-action button. Set the button text (e.g., "Download Now") and link (e.g., App Store or Play Store URL).

Edit or Remove

Reorder slides by dragging, edit content by clicking the edit icon, or remove slides you no longer need.

Tip

Use high-contrast images with minimal text overlays for maximum impact. Ensure images are optimized for web to maintain fast page load times.

Feature Sections

Highlight the key features of your platform with icons and descriptions:

Field Description Example
Section Title Heading for the features section "Why Choose Livriko?"
Feature Icon Font Awesome icon class fas fa-bolt
Feature Title Short feature name "Fast Booking"
Feature Description Brief explanation of the feature "Book a ride in under 30 seconds"

Download Section

Configure the App Store and Google Play download links:

Field Description
App Store URL Link to your app on the Apple App Store
Play Store URL Link to your app on Google Play
Download Section Title Heading for the download section (e.g., "Get the App")
Download Section Description Subtext encouraging downloads
Important

Ensure your app is published on both stores before adding download links. Broken links will hurt user trust and conversion rates.

Footer Configuration

Customize the landing page footer with your business information:

  • Company Name — Your business name
  • Contact Email — Support email address
  • Phone Number — Customer support phone
  • Address — Business address
  • Social Media Links — Facebook, Instagram, Twitter, LinkedIn
  • Privacy Policy URL — Link to your privacy policy page
  • Terms of Service URL — Link to your terms page

SEO Settings

Optimize your landing page for search engines:

Field Description Best Practice
Meta Title Title shown in search results Keep under 60 characters, include brand name
Meta Description Description shown in search results Keep under 160 characters, include call-to-action
Keywords Comma-separated keywords Include location, service type, and brand terms

Maintenance Mode

Enable maintenance mode to show a custom message while you make updates:

Enable Maintenance Mode

Toggle the "Maintenance Mode" switch in the landing page settings.

Set Custom Message

Enter a custom maintenance message (e.g., "We're updating our platform. We'll be back soon!").

Preview Before Publishing

Use the "Preview" button to see how the maintenance page looks before going live.

Updating the Landing Page

To update your landing page:

Log In to Admin Panel

Access your Livriko admin panel and navigate to Settings → Landing Page.

Modify Fields

Edit the desired fields, upload new images, and configure sections.

Preview Changes

Use the preview feature to see how changes look before publishing.

Save and Publish

Click "Save" to publish your changes. The landing page will update immediately.

Best Practice

Keep your landing page concise and focused on converting visitors to app downloads. Include clear call-to-action buttons linking to the App Store and Google Play. A/B test different hero images and CTAs to optimize conversion rates.
