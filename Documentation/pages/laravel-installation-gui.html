Livriko v1.0 · Based on Taxido

Livriko Laravel API (GUI)

This guide walks you through installing the Livriko Backend API using the web-based GUI installer. The wizard handles environment checks, database configuration, migrations, and initial setup automatically — no command-line knowledge required.

Before You Start
Ensure you have all prerequisites installed (PHP 8.2+, Composer, MySQL 8.0) and a local server environment running (XAMPP, MAMP, or LAMP). Also create an empty MySQL database before running the installer.

Step 1: Clone the Repository

Clone the Livriko source code from GitHub into your web server's root directory.

# Navigate to your web server root
cd C:\xampp\htdocs              # Windows (XAMPP)
cd /Applications/MAMP/htdocs    # macOS (MAMP)
cd /var/www/html                # Linux

# Clone the repository
git clone https://github.com/HitechFacilitator/livriko.git

# Navigate to the Laravel backend
cd livriko/Taxido_laravel
Server EnvironmentInstallation Path
XAMPP (Windows)C:\xampp\htdocs\livriko\Taxido_laravel
MAMP (macOS)/Applications/MAMP/htdocs/livriko/Taxido_laravel
LAMP (Linux)/var/www/html/livriko/Taxido_laravel

Step 2: Install Dependencies

Install all PHP packages required by Livriko using Composer. This downloads Laravel 12 and every dependency listed in composer.json.

# From the Taxido_laravel directory
composer install
Memory Limit Error?
If Composer reports a memory limit error, increase the limit in your php.ini: memory_limit = 512M. Alternatively, run composer install --no-dev to skip development dependencies.

Step 3: Environment Configuration

Create the .env file by copying the example template. This file holds your database credentials, application URL, API keys, and all configuration values.

# Copy the example environment file
cp .env.example .env

Open the .env file and configure the following values:

# APPLICATION SETTINGS
APP_NAME=Livriko
APP_ENV=local
APP_DEBUG=true
APP_URL=http://localhost:8000

# DATABASE CONNECTION
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=livriko_db
DB_USERNAME=root
DB_PASSWORD=

# SESSION & CACHE
CACHE_DRIVER=file
QUEUE_CONNECTION=sync
SESSION_DRIVER=file
Create the Database First
Before running the installer, create an empty MySQL database via phpMyAdmin (http://localhost/phpmyadmin) or the MySQL CLI: CREATE DATABASE livriko_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

Step 4: Generate Application Key

Laravel uses an encryption key for securing sessions, tokens, and sensitive data. Generate this key before launching the installer.

# Generate the application encryption key
php artisan key:generate

# You should see:
# Application key set successfully.
Do Not Skip This Step
If you skip generating the application key, Laravel will throw a No application encryption key has been specified error. Always run php artisan key:generate before launching the installer.

Step 5: Run Migrations and Seeders

Run the database migrations to create all required tables, then seed them with default data including admin accounts, vehicle types, zones, and platform settings.

# Run all migrations and seeders in one command
php artisan migrate --seed

The seeders populate the database with:

  • Admin account — Default login credentials for the admin panel
  • Vehicle types — Pre-configured ride categories (Economy, Premium, etc.)
  • Platform settings — Default currencies, languages, tax rates, and SMS configurations
  • Zone data — Sample service zones for ride operations
Fresh Install Only
If you have an existing database and want to start fresh, run php artisan migrate:fresh --seed to drop all tables and re-run from scratch.

Step 6: Configure Storage Link

Create a symbolic link from public/storage to storage/app/public so uploaded files (profile photos, vehicle images, documents) are accessible via the web.

# Create the storage symlink
php artisan storage:link
Permission Issues?
On shared hosting, symlink creation may fail due to restricted permissions. In that case, contact your hosting provider or manually create the link via cPanel File Manager. On Linux/Mac, ensure the storage directory has write permissions: chmod -R 775 storage/

Step 7: Start the Development Server

Start the Laravel Artisan development server to test your installation:

# Start the development server
php artisan serve

You should see output like:

   INFO  Server running on [http://127.0.0.1:8000].

  Press Ctrl+C to stop the server.

Verify Your Installation

Open your browser and verify everything is working:

If you can log in to the admin panel, the GUI installation is successful. You can now proceed to configure your mobile apps or deploy to production.
Change Default Password
Change the default admin password immediately after your first login. The default credentials are publicly documented and must never be used in a production environment.

Common Issues

"No application encryption key"

Run php artisan key:generate before starting the server. The .env file must have a valid APP_KEY value.

"Connection refused" for MySQL

Ensure MySQL is running. Check that DB_HOST, DB_PORT, DB_USERNAME, and DB_PASSWORD in .env match your MySQL configuration.

"Permission denied" on storage

Run chmod -R 775 storage/ bootstrap/cache/ to grant write permissions to the web server.
