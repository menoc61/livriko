cPanel Server Deployment (GUI)

This guide walks you through deploying the Livriko Backend API to a shared hosting environment using cPanel's web-based tools. This is the simplest deployment method — no command-line access required.

Shared Hosting
cPanel deployment is suitable for shared hosting plans. For better performance, scalability, and more control, consider a VPS deployment instead.

Step 1: Upload Files

Upload the Livriko source code to your hosting account using cPanel's File Manager or an FTP client like FileZilla.

1.1 Log in to cPanel

Access your cPanel dashboard at https://yourdomain.com:2083 or via your hosting provider's control panel link.

1.2 Open File Manager

Navigate to Files → File Manager and go to your domain's document root (usually public_html).

1.3 Upload and Extract

Upload the Livriko zip file, extract it, and move the contents of Taxido_laravel to your desired location.

Your directory structure should look like this:

public_html/
└── livriko/
    ├── app/
    ├── bootstrap/
    ├── config/
    ├── database/
    ├── public/       ← Set this as document root
    ├── resources/
    ├── routes/
    ├── storage/
    └── .env.example
Document Root
The public directory must be set as the document root. Never point your domain to the Laravel root directory — this exposes sensitive files like .env and composer.json.

Step 2: Create MySQL Database

Create a new MySQL database through cPanel's database management tools.

2.1 Open MySQL Database Wizard

Go to Databases → MySQL Database Wizard for the guided setup, or use MySQL Databases for manual creation.

2.2 Create Database

Enter a database name (e.g., livriko_db). The full name will be prefixed with your cPanel username: yourusername_livriko_db.

2.3 Create Database User

Create a new user with a strong password. The full username will be: yourusername_dbuser.

2.4 Grant All Privileges

Add the user to the database and grant ALL PRIVILEGES. Click Make Changes to save.

Save Your Credentials
Write down the full database name, username, and password. You'll need these for the .env configuration in the next step.

Step 3: Configure .env

Create the .env file using cPanel's File Manager.

3.1 Copy .env.example

In File Manager, navigate to the livriko folder. Right-click .env.example and select Copy. Rename the copy to .env.

3.2 Edit .env

Right-click .env and select Edit. Update the following values with your actual credentials:

APP_NAME=Livriko
APP_ENV=production
APP_KEY=
APP_DEBUG=false
APP_URL=https://yourdomain.com/livriko/public

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=yourusername_livriko_db
DB_USERNAME=yourusername_dbuser
DB_PASSWORD=your_database_password

MAIL_MAILER=smtp
MAIL_HOST=smtp.mailtrap.io
MAIL_PORT=2525
MAIL_USERNAME=null
MAIL_PASSWORD=null
MAIL_ENCRYPTION=null

Step 4: Run Migrations

Open your browser and navigate to the Livriko public URL to run the database migrations:

https://yourdomain.com/livriko/public

If using the GUI installer, follow the on-screen wizard. Alternatively, if you have cPanel Terminal access:

# Navigate to the Laravel directory
cd ~/public_html/livriko/Taxido_laravel

# Generate application key
php artisan key:generate

# Run migrations and seeders
php artisan migrate --seed

# Create storage symlink
php artisan storage:link

Step 5: Set Permissions

If you encounter permission errors, set the correct file permissions via File Manager.

# Key directories that need write access:
storage/              → 775
storage/app/          → 775
storage/framework/    → 775
storage/logs/         → 775
bootstrap/cache/      → 775

Step 6: Set Document Root

Point your domain's document root to the public directory.

6.1 Open Domains

Go to Domains in cPanel and click Manage next to your domain.

6.2 Update Document Root

Set the Document Root to: livriko/public and click Update.

Step 7: Configure Cron Jobs

Laravel requires a cron job for scheduled tasks (sending emails, cleaning up sessions, etc.).

7.1 Open Cron Jobs

Go to Advanced → Cron Jobs in cPanel.

7.2 Add Cron Job

Set the schedule to Once Per Minute (* * * * *) and add this command:

cd ~/public_html/livriko/Taxido_laravel && php artisan schedule:run >> /dev/null 2>&1
Deployment Complete
Access https://yourdomain.com/admin and log in with admin@livriko.com / password to verify the deployment. Remember to change the default password immediately.
