App Installation

Follow these steps to install and configure both the Livriko User App and Driver App on your local development environment. The repository contains two separate React Native projects.

Warning

The Livriko backend API must be installed and running before you can test the mobile apps. Ensure your Laravel backend is up and accessible at a known URL before proceeding.

Step 1: Clone the Repository

Clone the Livriko repository to your local machine and inspect the directory structure:

git clone https://github.com/your-repo/livriko.git
cd livriko

The repository contains two mobile app directories:

  • Taxido_user/ — The passenger-facing User App
  • Taxido_driver/ — The driver-facing Driver App

Step 2: Install User App Dependencies

Navigate to the User App directory and install all required packages:

cd Taxido_user
npm install

This installs all React Native dependencies including navigation, maps, state management, and UI components. The installation may take a few minutes depending on your connection speed.

Tip

If npm install fails, try running npm install --force or delete node_modules and package-lock.json before retrying.

Step 3: Install Driver App Dependencies

Repeat the process for the Driver App:

cd ../Taxido_driver
npm install

The Driver App has a similar but slightly different dependency set, including additional packages for background location tracking and navigation.

Step 4: Configure Environment

Both apps require two key configuration values before they can communicate with your backend.

User App Configuration

API URL — Open Taxido_user/src/config/config.tsx and set your backend API URL:

// Taxido_user/src/config/config.tsx
export const URL = 'https://your-backend-url.com';

Google Maps API Key — Open Taxido_user/src/context/index.tsx and add your Google Maps key:

// Taxido_user/src/context/index.tsx
export const GOOGLE_MAPS_API_KEY = 'YOUR_GOOGLE_MAPS_API_KEY';

Driver App Configuration

API URL — Open Taxido_driver/src/config/config.tsx and set the same backend API URL:

// Taxido_driver/src/config/config.tsx
export const URL = 'https://your-backend-url.com';

Google Maps API Key — Open Taxido_driver/src/context/index.tsx and add your Google Maps key:

// Taxido_driver/src/context/index.tsx
export const GOOGLE_MAPS_API_KEY = 'YOUR_GOOGLE_MAPS_API_KEY';
Note

Both apps must use the same API URL and Google Maps API key. See Environment URL for more details on dev vs. production configuration.

Step 5: Run the Apps

Android

For the User App:

cd Taxido_user
npm run android

For the Driver App:

cd Taxido_driver
npm run android

iOS

For iOS, you must first install CocoaPods dependencies. Run these commands from the app directory:

cd Taxido_user/ios
pod install
cd ..
npm run ios

Repeat for the Driver App:

cd Taxido_driver/ios
pod install
cd ..
npm run ios
Important

Always open the .xcworkspace file (not .xcodeproj) when working with the iOS project in Xcode after running pod install. The workspace includes both your project and the Pods project.

Troubleshooting Installation

If you encounter issues during installation, here are the most common problems and their solutions:

Issue Cause Solution
npm install fails with peer dependency errors Package version conflicts Run npm install --legacy-peer-deps or delete node_modules and package-lock.json before retrying
pod install fails on iOS Outdated CocoaPods cache Run pod deintegrate && pod install or pod repo update
Metro bundler won't start Port 8081 is already in use Kill the process: lsof -i :8081 then kill -9 <PID>
SDK not found during Android build ANDROID_HOME not set Set the ANDROID_HOME environment variable and restart your terminal
App shows blank screen API URL misconfigured Check that the URL in config.tsx is correct and accessible
Tip

For a completely fresh start, you can delete all generated files and reinstall from scratch:

# Complete reset
cd Taxido_user
rm -rf node_modules package-lock.json
npm install
cd android && ./gradlew clean && cd ../..

Verifying the Installation

After installation, verify everything is working by checking these indicators:

  • npm install completes without errors — all dependencies are resolved
  • Metro bundler starts on port 8081 without warnings
  • Android build completes and the app launches on the emulator
  • iOS build completes and the app launches on the simulator
  • API connection — the app loads data from the backend (vehicle types, pricing, etc.)
  • Google Maps — the map renders correctly with your API key

For more detailed troubleshooting, see the App Errors page.
