SHA Key

SHA certificate fingerprints are required by Firebase to verify your Android app's identity. You need to generate and register both SHA-1 and SHA-256 keys.

Why SHA Keys Are Needed

Firebase uses SHA certificate fingerprints to verify the identity of your Android app. SHA keys are required for:

Feature Requirement
Google Sign-In SHA-1 key is required to authenticate with Google services
App Links / Dynamic Links SHA-256 key is required for deep linking and app verification
Firebase App Check SHA keys help verify that requests come from your genuine app
Play App Signing Google Play uses SHA keys to verify your app's identity

Generate SHA Keys

You need both SHA-1 and SHA-256 fingerprints. Use the keytool command (included with Java JDK) to generate them.

Generate Debug SHA Keys

For development and testing, use the debug keystore:

# Generate SHA-1 and SHA-256 from debug keystore
keytool -list -v \
  -alias androiddebugkey \
  -keystore ~/.android/debug.keystore \
  -storepass android

The output will display both fingerprints:

Certificate fingerprints:
  SHA1: XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX
  SHA256: XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX
Note

The debug keystore password is android by default. The debug keystore is located at ~/.android/debug.keystore on macOS/Linux and C:\Users\<username>\.android\debug.keystore on Windows.

Generate Release SHA Keys

For production builds, use your release keystore:

# Generate SHA-1 and SHA-256 from release keystore
keytool -list -v \
  -alias your-key-alias \
  -keystore /path/to/your-release.keystore \
  -storepass your-keystore-password
Warning

Keep your release keystore password secure. Never commit it to version control. Store it in a secure password manager or environment variable.

Add SHA Keys to Firebase

Open Firebase Console

Go to Firebase Console → Project Settings (gear icon in the top-left).

Select Your Android App

Scroll down to the "Your apps" section and select your Android app.

Add SHA Fingerprint

Click "Add fingerprint", paste the SHA-1 key, and click "Save".

Add SHA-256

Repeat the process for the SHA-256 key. Both fingerprints should now be listed.

Download Updated Config

After adding SHA keys, download an updated google-services.json and replace the existing file in your project.

Debug vs Release Keystores

Keystore Location Use Case
Debug ~/.android/debug.keystore Development and testing on local devices/emulators
Release Your custom path (e.g., android/app/release.keystore) Production builds uploaded to the Play Store
Google Play App Signing Managed by Google Play Console Automatically managed when using Play App Signing
Google Play App Signing

If you use Google Play App Signing, you also need the upload certificate SHA-1 from the Play Console (Release → Setup → App signing). Add this to Firebase as well.

Common Issues with Missing SHA Keys

Issue Symptom Fix
Google Sign-In fails Error: "12500" or sign-in popup closes immediately Add SHA-1 key to Firebase and download updated google-services.json
Dynamic Links not working App doesn't open when clicking a link Add SHA-256 key to Firebase
Firebase Auth fails silently Social login works in debug but not in release Add release SHA keys to Firebase
Play Store rejection App crashes on sign-in for Play Store users Add the Play Console upload certificate SHA-1
