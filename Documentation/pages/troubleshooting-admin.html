Admin Common Errors

Below are the most common errors encountered when running the Livriko Laravel admin panel, along with their causes and solutions.

"500 Internal Server Error"

Cause Solution
Stale cached configuration Run the following commands to clear all caches:
php artisan cache:clear
php artisan config:clear
php artisan route:clear
php artisan view:clear
php artisan event:clear
Application in maintenance mode Run php artisan down to disable maintenance mode
PHP version incompatibility Ensure your server runs PHP 8.1 or higher. Check with php --version
Missing PHP extensions Install required extensions: mbstring, xml, ctype, json, bcmath, pdo_mysql

"Class not found" Error

Cause Solution
Autoload not regenerated Run composer dump-autoload
Missing composer dependency Run composer install to install all dependencies
Namespace mismatch Check that the class namespace matches the directory structure

"Token Mismatch" Error

Cause Solution
CSRF token expired Clear the config cache: php artisan config:clear
Session driver misconfigured Check SESSION_DRIVER in .env (use file or database)
Browser cookie issues Clear browser cookies and cache, then try again

Database Connection Error

Cause Solution
Incorrect database credentials in .env Verify the following values:
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=livriko
DB_USERNAME=root
DB_PASSWORD=your_password
Database server not running Start MySQL: sudo systemctl start mysql
Database does not exist Create the database: mysql -u root -p -e "CREATE DATABASE livriko"
User lacks privileges Grant privileges: GRANT ALL ON livriko.* TO 'username'@'localhost'

Login Issues

Cause Solution
Admin user not seeded Run the seeder: php artisan db:seed --class=AdminSeeder
Incorrect password Reset the password: php artisan tinker then User::where('email', 'admin@example.com')->update(['password' => Hash::make('new-password')])
Account locked Check the users table for lock status and reset if needed

"Permission denied" Error

Cause Solution
Incorrect directory permissions Set the correct permissions:
chmod -R 775 storage
chmod -R 775 bootstrap/cache
chown -R www-data:www-data storage
chown -R www-data:www-data bootstrap/cache
Storage link not created Create the storage link: php artisan storage:link

Email Not Sending

Cause Solution
Incorrect SMTP configuration Verify SMTP settings in .env:
MAIL_MAILER=smtp
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=your-email@gmail.com
MAIL_PASSWORD=your-app-password
MAIL_ENCRYPTION=tls
App-specific password required For Gmail, generate an app-specific password in your Google account settings
Config cache stale Run php artisan config:clear after changing mail settings

Queue Not Processing

Cause Solution
Queue worker not running Start the queue worker:
php artisan queue:work --sleep=3 --tries=3
Supervisor process crashed Restart Supervisor:
sudo supervisorctl restart all
Redis not running Start Redis: sudo systemctl start redis

Migration Errors

Cause Solution
MySQL version incompatibility Livriko requires MySQL 5.7+ or 8.0+. Check with mysql --version
Column already exists Rollback and re-migrate: php artisan migrate:rollback && php artisan migrate
Table does not exist Run all migrations from the beginning: php artisan migrate:fresh --seed
Debugging Tip

When troubleshooting, always check the Laravel log file first: tail -100 storage/logs/laravel.log. The log file contains detailed error messages that will help you identify the root cause.
