Firebase Cloud Functions

Cloud Functions for Firebase allow you to run backend code in response to events triggered by Firebase features and HTTP requests. Livriko uses Cloud Functions for automated notifications and background processing.

What Are Cloud Functions?

Cloud Functions are serverless functions that execute in a managed environment. They scale automatically and you only pay for what you use.

Trigger Type Description Livriko Use Case
Firestore changes Created, updated, or deleted documents Trigger notifications when ride status changes
Auth events User creation, deletion, or password reset Initialize rider/driver profiles on sign-up
HTTP requests Custom API endpoints Webhook endpoints for payment confirmations
Scheduled (Cron) Time-based triggers Periodic cleanup of expired sessions

Use Cases in Livriko

Cloud Functions power several critical features in the Livriko platform:

Ride Notifications

Automatically send push notifications when a ride is requested, accepted, started, or completed.

Location Updates

Broadcast driver location changes to connected riders in real time.

Payment Webhooks

Process payment confirmations from external payment gateways.

Data Cleanup

Periodically clean up expired sessions, old notifications, and stale data.

Setup

Install Firebase CLI

# Install Firebase CLI globally
npm install -g firebase-tools

# Verify installation
firebase --version

Login to Firebase

# Authenticate with your Firebase account
firebase login

# This opens a browser for Google OAuth authentication
# After login, your credentials are stored locally

Initialize Functions in Your Project

# Navigate to your Livriko project root
cd your-livriko-project

# Initialize Firebase Functions
firebase init functions

# Select your Firebase project when prompted
# Choose JavaScript as the language
# Choose No for ESLint (unless you prefer it)
# Choose Yes to install dependencies

Update Project Configuration

Update the .firebaserc file in your project root with your Firebase project ID:

{
  "projects": {
    "default": "your-firebase-project-id"
  }
}

Livriko Cloud Functions

Livriko includes the following pre-configured Cloud Functions:

Function Trigger Description
trackOrder Firestore write Updates order status and notifies riders of delivery progress
updateLocation Firestore write Broadcasts driver location changes to connected riders
sendNotification Firestore write Sends FCM push notifications when new documents are created in the notifications collection
cleanUpSessions Scheduled (daily) Removes expired user sessions and stale data from Firestore

Function Example

Here's an example of how Livriko's Cloud Functions are structured:

const functions = require('firebase-functions');
const admin = require('firebase-admin');

admin.initializeApp();

// Send notification when a ride is requested
exports.onRideRequested = functions.firestore
    .document('rides/{rideId}')
    .onCreate(async (snap, context) => {
      const ride = snap.data();

      // Find nearby drivers
      const driversSnapshot = await admin.firestore()
          .collection('drivers')
          .where('status', '==', 'online')
          .get();

      const tokens = [];
      driversSnapshot.forEach(doc => {
        const data = doc.data();
        if (data.fcmToken) {
          tokens.push(data.fcmToken);
        }
      });

      // Send notification to all online drivers
      const notification = {
        notification: {
          title: 'New Ride Request',
          body: `Ride from ${ride.pickupAddress}`,
        },
        data: {
          rideId: context.params.rideId,
          type: 'ride_requested',
        },
      };

      return admin.messaging().sendEachForMulticast({
        tokens,
        ...notification,
      });
    });

Deploying Functions

# Deploy all functions
firebase deploy --only functions

# Deploy a specific function
firebase deploy --only functions:onRideRequested

# Deploy with project flag
firebase deploy --only functions --project your-project-id
Note

The Cloud Functions source code is located in the functions/ directory of your Livriko project. Do not modify function files unless you are familiar with Node.js and Firebase APIs.

Testing Functions

Test your Cloud Functions before deploying to production:

# Start the Firebase emulator suite
firebase emulators:start

# Functions will be available at:
# http://localhost:5001/your-project-id/us-central1/functionName

# Test Firestore-triggered functions by writing to Firestore
# Use the Firebase Console or the admin SDK

Viewing Function Logs

# View real-time function logs
firebase functions:log

# View logs for a specific function
firebase functions:log --only onRideRequested

# View logs from the last 24 hours
firebase functions:log --since 24h
Important

Cloud Functions have execution time limits. Firestore-triggered functions have a 60-second limit, while HTTP functions have a 60-minute limit. Optimize your functions to complete within these timeframes.
