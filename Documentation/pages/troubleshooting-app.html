App Common Errors

Below are the most common errors encountered when building or running the Livriko mobile apps, along with their causes and solutions.

Build Errors — Android

"SDK not found"

Cause Solution
Android SDK not installed or not in PATH Install the Android SDK via Android Studio. Ensure ANDROID_HOME environment variable is set correctly.
Wrong SDK version Check android/build.gradle for required SDK version and install it via Android Studio SDK Manager.

"Could not resolve dependencies"

Cause Solution
Corrupted node_modules Run rm -rf node_modules && npm install --force
Package version conflicts Check package.json for conflicting dependencies and resolve version mismatches

"Gradle build failed"

Cause Solution
Stale build cache Run cd android && ./gradlew clean, then rebuild the app
Memory issues Increase Gradle memory in gradle.properties: org.gradle.jvmargs=-Xmx4096m
Missing google-services.json Ensure google-services.json is placed in android/app/

Build Errors — iOS

"Corrupted CocoaPods cache"

Cause Solution
Stale or corrupted pod cache Run cd ios && pod deinstall && pod install, then rebuild the app
Podfile.lock conflicts Delete Podfile.lock, run pod install again

"No signing certificate found"

Cause Solution
Missing Apple Developer account Enroll in the Apple Developer Program and configure signing in Xcode
Wrong team selected In Xcode, go to your target's Signing & Capabilities and select the correct team

Runtime Errors

"Network request failed"

Cause Solution
Incorrect API URL in config.tsx Verify the API_URL value matches your backend URL (e.g., http://192.168.1.100/livriko/public/api)
Backend server is not running Ensure your Laravel backend is running and accessible from your device or emulator
Network connectivity issue Check that your device/emulator has internet access and can reach the backend server
HTTP vs HTTPS mismatch On iOS, ensure you're using HTTPS or configure App Transport Security for HTTP

"Firebase not initialized"

Cause Solution
google-services.json not in the correct location (Android) Ensure the file is placed in android/app/google-services.json
GoogleService-Info.plist not in the correct location (iOS) Ensure the file is placed in ios/GoogleService-Info.plist
Missing configuration file Re-download the config file from the Firebase console and rebuild the app

"Map not loading"

Cause Solution
Missing or invalid Google Maps API key Verify the API key in the Google Cloud Console
Required APIs not enabled Enable Maps SDK for Android and Maps SDK for iOS in the Cloud Console
API key restrictions Check that the API key has the correct application restrictions and API restrictions

"Push notification not working"

Cause Solution
FCM token not registered Ensure the app successfully registers the FCM token with the backend
Missing notification permission On Android 13+, check that notification permission is granted. On iOS, check notification settings.
FCM Server Key not configured Verify the Server Key in the admin panel Settings → Firebase section

"Permission denied"

Cause Solution
Missing permissions in AndroidManifest.xml Add the required permission entries (e.g., ACCESS_FINE_LOCATION, INTERNET)
Missing permissions in Info.plist (iOS) Add the required NSLocationWhenInUseUsageDescription and other permission descriptions

Quick Fix Reference

Error Quick Fix
Stale build cache cd android && ./gradlew clean
Corrupted node_modules rm -rf node_modules && npm install --force
CocoaPods issues cd ios && pod deinstall && pod install
Firebase config missing Re-download config files from Firebase Console
Maps not loading Verify API key and enable required APIs in Cloud Console
