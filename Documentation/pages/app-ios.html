iOS Setup

This guide walks you through setting up your macOS development environment for building and running the Livriko User App and Driver App on iOS devices and simulators.

Note

iOS development requires a Mac computer running macOS. iOS apps cannot be built on Windows or Linux.

Install Xcode

Download and install Xcode from the Mac App Store. The minimum required version is Xcode 15.

Configure Command Line Tools

After installing Xcode, open a terminal and run the following to ensure the correct developer tools are active:

sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer
xcodebuild -version  # Should show Xcode 15.x or later
Tip

If you have multiple Xcode versions installed, use xcode-select -p to verify which one is currently active. Switch with sudo xcode-select -s /Applications/Xcode_15.app/Contents/Developer.

Install CocoaPods

CocoaPods is the dependency manager for iOS projects. Install it using RubyGems:

# Install CocoaPods (requires sudo on some systems)
sudo gem install cocoapods

# Initialize the CocoaPods spec repository
pod setup

# Verify installation
pod --version
Note

If you are using macOS Ventura or later, you may need to install Ruby via Homebrew first:

brew install ruby
gem install cocoapods

Apple Developer Account

An Apple Developer Account is required for certain features and for publishing to the App Store:

Feature Requires Developer Account?
Run on iOS Simulator No
Run on physical iPhone Yes (free account works for development)
Push Notifications (APNs) Yes ($99/year)
Sign In with Apple Yes ($99/year)
Background Location Yes ($99/year)
App Store Submission Yes ($99/year)

To enroll, visit developer.apple.com/programs and sign up for the Apple Developer Program ($99/year).

Provisioning Profiles and Certificates

To run apps on a physical device or submit to the App Store, you need to configure signing certificates and provisioning profiles:

  1. Log in to Apple Developer Account
  2. Navigate to Certificates, Identifiers & Profiles
  3. Create a new App ID for each app (e.g., com.livriko.user and com.livriko.driver)
  4. Generate a Distribution Certificate for App Store builds
  5. Create a Provisioning Profile linking the certificate to your App ID
  6. Download and install both the certificate and provisioning profile on your Mac
Tip

Xcode can automatically manage signing if you enable Automatically manage signing in the project's Signing & Capabilities tab. This is recommended for development builds.

Info.plist Permissions

The Livriko apps require several iOS permissions configured in Info.plist. Ensure the following keys are present in both the User App and Driver App:

Key Purpose Required By
NSLocationWhenInUseUsageDescription Location access while app is in use User App + Driver App
NSLocationAlwaysAndWhenInUseUsageDescription Background location access Driver App only
NSCameraUsageDescription Camera access for document upload Driver App only
NSPhotoLibraryUsageDescription Photo library access for profile pictures User App + Driver App
UIBackgroundModes (location) Background location tracking Driver App only

iOS Simulator

Xcode includes the iOS Simulator for testing without a physical device:

  1. Open Xcode
  2. Go to Xcode → Open Developer Tool → Simulator
  3. Or launch from the terminal: open -a Simulator
  4. Choose a device from Hardware → Device (e.g., iPhone 15 Pro)

Project Setup

After cloning the repository and installing dependencies, install CocoaPods for each app:

User App

cd Taxido_user/ios
pod install
cd ..
npm run ios

Driver App

cd Taxido_driver/ios
pod install
cd ..
npm run ios
Important

Always open the .xcworkspace file (not .xcodeproj) when working with the iOS project in Xcode after running pod install. Running pod install generates a workspace that includes both your project and the Pods project.

# Open the workspace in Xcode
open Taxido_user/ios/Taxido_user.xcworkspace
# or for the Driver App:
open Taxido_driver/ios/Taxido_driver.xcworkspace

Troubleshooting iOS Setup

Common issues encountered during iOS environment setup and their solutions:

Issue Solution
pod install fails with version conflicts Run pod repo update then retry. If still failing, delete Podfile.lock and run pod install again.
Xcode shows "No matching provisioning profiles" Ensure your Apple Developer account is configured in Xcode → Preferences → Accounts. Enable automatic signing.
Build fails with "Module not found" for Pods Run cd ios && pod deintegrate && pod install to rebuild the Pods workspace from scratch.
Simulator crashes on launch Reset the simulator: xcrun simctl shutdown all && xcrun simctl erase all

Xcode Project Settings

After opening the .xcworkspace file, review these project settings in Xcode:

  • Deployment Target — Set to iOS 15.1 or higher in the project's Build Settings
  • Signing & Capabilities — Select your development team and verify the bundle identifier
  • Build Settings — Ensure IPHONEOS_DEPLOYMENT_TARGET is set correctly
