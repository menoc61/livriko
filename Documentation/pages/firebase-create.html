Create Firebase Project

This guide walks you through creating a Firebase project and registering both the User and Driver apps for Livriko.

Prerequisites

Before you begin, make sure you have:

  • A Google Account (required for Firebase Console access)
  • The package names for your Android and iOS apps
  • Access to your project's android/ and ios/ directories

Step 1: Create the Firebase Project

Navigate to the Firebase Console

Go to console.firebase.google.com and sign in with your Google account.

Click "Add project"

On the Firebase Console dashboard, click the "Add project" button to start the project creation wizard.

Enter Project Name

Enter a project name (e.g., Livriko). This name is for your reference and does not need to match your app name. Click "Continue".

Configure Google Analytics (Optional)

You can enable or disable Google Analytics based on your preference. If enabled, select your Analytics account. Click "Create project" and wait for provisioning to complete.

Note

Project provisioning typically takes 1–2 minutes. You will see a progress indicator. Once complete, click "Continue" to enter the project dashboard.

Step 2: Add Android App (User)

Start App Registration

From the Firebase console project overview, click the Android icon (or "Add app" → Android).

Enter Package Name

Enter the Android package name: com.livriko.user

Enter an app nickname (e.g., Livriko User) for your reference.

Register the App

Click "Register app" to register your Android application.

Download Configuration File

Download the google-services.json file. Place it in your User App's android/app/ directory:

user-app/android/app/google-services.json
Important

The google-services.json file contains your Firebase project configuration including API keys and project IDs. Do not modify its contents manually and never commit it to public repositories.

Step 3: Add iOS App (User)

Start iOS Registration

From the Firebase console, click "Add app" and select iOS.

Enter Bundle ID

Enter the iOS bundle ID: com.livriko.user

Enter an app nickname (e.g., Livriko User iOS).

Register and Download

Click "Register app", then download the GoogleService-Info.plist file.

Place the File

Move the downloaded file to your User App's ios/ directory:

user-app/ios/GoogleService-Info.plist

Step 4: Add Apps for Driver

Repeat Steps 2 and 3 for the Driver app using the following identifiers:

Platform Package / Bundle ID Config File Destination
Android com.livriko.driver google-services.json android/app/
iOS com.livriko.driver GoogleService-Info.plist ios/
Warning

Each app (User and Driver) must be registered separately in Firebase. Do not reuse the same google-services.json across different apps. Each app gets its own configuration file with unique API keys.

Configuration File Locations

After completing the setup, your project structure should look like this:

livriko/
├── user-app/
│   ├── android/
│   │   └── app/
│   │       └── google-services.json
│   └── ios/
│       └── GoogleService-Info.plist
└── driver-app/
    ├── android/
    │   └── app/
    │       └── google-services.json
    └── ios/
        └── GoogleService-Info.plist

Verifying Your Setup

After placing the configuration files, verify that Firebase is properly initialized:

Platform Verification Method
Android Build the app — if google-services.json is correctly placed, the build will succeed without errors
iOS Open the project in Xcode — GoogleService-Info.plist should appear in the project navigator
Admin Panel Check the Firebase project console — your registered apps should appear in the project overview
