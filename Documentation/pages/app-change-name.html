Change App Name

Rename the Livriko User App and Driver App on both Android and iOS. The app name appears on the device home screen, in the app switcher, and in the app store listing.

User App — Android

Edit the AndroidManifest.xml file in the User App to change the app label displayed on the device home screen and in the app switcher:

File: Taxido_user/android/app/src/main/AndroidManifest.xml

<application
  android:name=".MainApplication"
  android:label="@string/app_name"
  android:icon="@mipmap/ic_launcher"
  android:roundIcon="@mipmap/ic_launcher_round"
  ...>

The @string/app_name reference points to the string resource file. Edit it to change the display name:

File: Taxido_user/android/app/src/main/res/values/strings.xml

<resources>
    <string name="app_name">YourAppName</string>
</resources>
Note

You can also change the app name in different languages by creating localized strings.xml files in values-fr/, values-de/, etc.

User App — iOS

Edit the Info.plist file in the User App iOS project to change the display name shown on the home screen and in the app switcher:

File: Taxido_user/ios/Taxido_user/Info.plist

<key>CFBundleDisplayName</key>
<string>YourAppName</string>

You should also update the CFBundleName entry in the same file:

<key>CFBundleName</key>
<string>YourAppName</string>
Note

The iOS Xcode target may still be named TaxidoUserApp. You can rename it in Xcode by selecting the target in the project navigator and editing the "Product Name" build setting under Build Settings.

Driver App — Android

Edit the strings.xml file in the Driver App Android resources. This controls the app name displayed on the Android home screen and in the app switcher:

File: Taxido_driver/android/app/src/main/res/values/strings.xml

<resources>
    <string name="app_name">YourDriverAppName</string>
</resources>

iOS — Info.plist

Edit the Info.plist file in the Driver App iOS project to change the display name shown on the home screen:

File: Taxido_driver/ios/Taxido_driver/Info.plist

<key>CFBundleDisplayName</key>
<string>YourDriverAppName</string>

<key>CFBundleName</key>
<string>YourDriverAppName</string>

React Native app.json

You should also update the app.json file in the root of each app directory to keep the names consistent with the native configuration. This file is used by React Native's build system:

// Taxido_user/app.json
{
  "name": "YourAppName",
  "displayName": "YourAppName"
}

// Taxido_driver/app.json
{
  "name": "YourDriverAppName",
  "displayName": "YourDriverAppName"
}
Note

The name field must not contain spaces (use camelCase), while displayName can contain spaces and is what users see on the home screen.

Application ID

If you need to change the application ID (the unique identifier used for Play Store / App Store identification), edit the build.gradle file for Android and the Xcode project settings for iOS:

Android

File: Taxido_user/android/app/build.gradle

android {
    namespace "com.yourcompany.yourapp"
    defaultConfig {
        applicationId "com.yourcompany.yourapp"
        // ...
    }
}

iOS

Change the Bundle Identifier in Xcode: select the project in the navigator, go to the Signing & Capabilities tab, and update the bundle identifier.

Quick Reference

The following table summarizes all the files that need to be modified when changing the app name:

Platform File Change
React Native (User) Taxido_user/app.json name and displayName fields
React Native (Driver) Taxido_driver/app.json name and displayName fields
Android (User) Taxido_user/android/app/src/main/res/values/strings.xml app_name string resource
Android (Driver) Taxido_driver/android/app/src/main/res/values/strings.xml app_name string resource
iOS (User) Taxido_user/ios/Taxido_user/Info.plist CFBundleDisplayName and CFBundleName
iOS (Driver) Taxido_driver/ios/Taxido_driver/Info.plist CFBundleDisplayName and CFBundleName
Warning

After changing the app name or application ID, you must perform a clean build for the changes to take effect. Delete the build folder (Android) and DerivedData folder (iOS) before rebuilding.

# Android clean (User App)
cd Taxido_user/android
./gradlew clean
cd ../..
npm run android

# Android clean (Driver App)
cd Taxido_driver/android
./gradlew clean
cd ../..
npm run android

# iOS clean (User App)
rm -rf ~/Library/Developer/Xcode/DerivedData/Taxido_user-*
cd Taxido_user/ios
pod install
cd ..
npm run ios

# iOS clean (Driver App)
rm -rf ~/Library/Developer/Xcode/DerivedData/Taxido_driver-*
cd Taxido_driver/ios
pod install
cd ..
npm run ios

Verification

After rebuilding, verify the name change by checking the following locations on your device:

  • Home screen — The app icon label shows the new name
  • App switcher — The app card shows the new name in the multitasking view
  • Settings — The app appears with the new name in device settings
  • Push notifications — The notification header shows the new name
  • App Store / Play Store — After publishing, the store listing shows the new name
Tip

Keep the app name short (under 15 characters) so it displays correctly on all device home screens without truncation. Long names may be cut off on smaller devices.
