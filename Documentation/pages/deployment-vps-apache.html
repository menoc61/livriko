VPS Deployment — Apache Server (LAMP)

This guide covers deploying Livriko to a VPS running Apache with MySQL and PHP (LAMP stack). For better performance and lower memory usage, consider the Nginx deployment instead.

Root Access Required
This guide assumes you have root or sudo access to your VPS. All commands should be run as root or with sudo.

Step 1: Update System

Start by updating the system packages and installing required dependencies.

# Update system
sudo apt update && sudo apt upgrade -y

# Install required packages
sudo apt install -y software-properties-common curl git unzip

Step 2: Install Apache

Install and start the Apache web server.

# Install Apache
sudo apt install -y apache2

# Start and enable Apache
sudo systemctl start apache2
sudo systemctl enable apache2

# Verify Apache is running
sudo systemctl status apache2

Step 3: Install PHP 8.2

Install PHP 8.2 with all required extensions from the Ondrej PPA.

# Add PHP repository
sudo add-apt-repository ppa:ondrej/php -y
sudo apt update

# Install PHP 8.2 and extensions
sudo apt install -y php8.2 php8.2-cli php8.2-common php8.2-mysql \
  php8.2-xml php8.2-mbstring php8.2-curl php8.2-zip php8.2-gd \
  php8.2-bcmath php8.2-redis php8.2-fpm php8.2-intl

# Verify PHP version
php -v

Step 4: Install MySQL 8.0

Install MySQL and secure the installation.

# Install MySQL
sudo apt install -y mysql-server

# Secure the installation
sudo mysql_secure_installation

# Create database and user
sudo mysql -u root -p

CREATE DATABASE livriko_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'livriko'@'localhost' IDENTIFIED BY 'your_secure_password';
GRANT ALL PRIVILEGES ON livriko_db.* TO 'livriko'@'localhost';
FLUSH PRIVILEGES;
EXIT;

Step 5: Install Composer and Node.js

Install the PHP and JavaScript dependency managers.

# Install Composer
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer

# Install Node.js via NVM
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc
nvm install 20

# Verify installations
composer --version
node -v

Step 6: Deploy Livriko

Clone the repository, install dependencies, and configure the application.

# Clone the repository
cd /var/www
sudo git clone https://github.com/HitechFacilitator/livriko.git

# Set ownership
sudo chown -R www-data:www-data livriko
sudo chmod -R 755 livriko

# Navigate to Laravel directory
cd livriko/Taxido_laravel

# Install Composer dependencies
sudo -u www-data composer install --no-dev --optimize-autoloader

# Configure environment
sudo -u www-data cp .env.example .env
sudo -u www-data php artisan key:generate

Edit the .env file with your production settings:

APP_NAME=Livriko
APP_ENV=production
APP_DEBUG=false
APP_URL=https://yourdomain.com

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=livriko_db
DB_USERNAME=livriko
DB_PASSWORD=your_secure_password
# Run migrations and seeders
sudo -u www-data php artisan migrate --seed

# Create storage symlink
sudo -u www-data php artisan storage:link

# Optimize for production
sudo -u www-data php artisan config:cache
sudo -u www-data php artisan route:cache
sudo -u www-data php artisan view:cache

Step 7: Configure Apache Virtual Host

Create a virtual host configuration for Livriko.

sudo nano /etc/apache2/sites-available/livriko.conf

Add the following configuration:

<VirtualHost *:80>
    ServerName yourdomain.com
    ServerAlias www.yourdomain.com
    ServerAdmin admin@yourdomain.com
    DocumentRoot /var/www/livriko/Taxido_laravel/public

    <Directory /var/www/livriko/Taxido_laravel/public>
        Options -Indexes +FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/livriko-error.log
    CustomLog ${APACHE_LOG_DIR}/livriko-access.log combined
</VirtualHost>
# Enable the site
sudo a2ensite livriko.conf

# Disable default site (optional)
sudo a2dissite 000-default.conf

# Restart Apache
sudo systemctl restart apache2

Step 8: Enable Mod Rewrite

The mod_rewrite module is essential for Laravel's URL routing.

Critical Step
If mod_rewrite is not enabled, you will get 404 errors on all routes except the home page. This is the most common cause of deployment issues with Apache.
# Enable mod_rewrite
sudo a2enmod rewrite

# Restart Apache
sudo systemctl restart apache2

Step 9: Configure SSL with Certbot

Install a free SSL certificate from Let's Encrypt using Certbot.

# Install Certbot
sudo apt install -y certbot python3-certbot-apache

# Obtain SSL certificate
sudo certbot --apache -d yourdomain.com -d www.yourdomain.com

# Verify auto-renewal
sudo certbot renew --dry-run
Auto-Renewal
Certbot automatically configures a cron job to renew certificates before they expire. The --dry-run command tests the renewal process without actually renewing.

Step 10: Set Up Cron Jobs

Add the Laravel scheduler cron job for background task processing.

# Edit crontab for www-data user
sudo crontab -u www-data -e

# Add the following line:
* * * * * cd /var/www/livriko/Taxido_laravel && php artisan schedule:run >> /dev/null 2>&1

Step 11: Configure Firewall

Set up UFW firewall to allow only necessary traffic.

# Allow SSH
sudo ufw allow OpenSSH

# Allow HTTP and HTTPS
sudo ufw allow 'Apache Full'

# Enable firewall
sudo ufw enable

# Check status
sudo ufw status

Verify Deployment

Run these commands to verify everything is working correctly.

# Check Apache status
sudo systemctl status apache2

# Check MySQL status
sudo systemctl status mysql

# Check PHP version
php -v

# Test the application
curl -I https://yourdomain.com
Deployment Complete
Access https://yourdomain.com/admin and log in with admin@livriko.com / password to verify the deployment. Remember to change the default password immediately.
