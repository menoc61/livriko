Coupons

Coupons let you offer promotional discounts to riders, driving user acquisition, retention, and engagement. Create percentage-based or fixed-amount discount codes that riders apply during checkout to reduce their ride fare. Coupons are a powerful marketing tool for launching in new cities, rewarding loyal customers, and running seasonal promotions.

How Coupons Work

Understanding the coupon lifecycle from creation to redemption.

Coupon Lifecycle

  1. Creation — Admin creates a coupon with a code, discount type, value, validity period, and usage limits.
  2. Distribution — The coupon code is shared with riders via push notifications, email, social media, or in-app promotions.
  3. Redemption — Rider enters the coupon code during ride booking. The system validates the code and applies the discount.
  4. Tracking — Each redemption is logged. Admin can view usage statistics, total discounts given, and remaining uses.

Discount Types

  • Percentage (%) — Discounts the ride fare by a percentage (e.g., 20% off). Useful for promotions where the discount scales with the fare amount.
  • Flat Amount — Deducts a fixed amount from the ride fare (e.g., $5 off). Predictable for both the platform and the rider.

Creating a Coupon

Follow these steps to add a new promotional discount code.

1. Navigate to Coupons

Log in to the admin panel. Go to Livriko Management → Coupons. You will see a list of existing coupons with their status and usage statistics.

2. Click "Add New Coupon"

Click the Add New Coupon button to open the coupon creation form.

3. Configure Coupon Details

Enter the coupon code, discount type and value, minimum fare requirements, maximum discount cap, validity period, and usage limits. See the field reference table below.

4. Set Validity Period

Configure the start date and end date for the coupon. The coupon is only valid within this date range. Expired coupons are automatically rejected during redemption.

5. Save and Distribute

Set the Status to Active and click Save. Share the coupon code with riders through your marketing channels.

Field Reference

Complete reference for every field on the coupon form.

Field Type Required Description
Code Text Yes The promo code riders enter during checkout (e.g., WELCOME20, SUMMER50, FIRST2024). Case-insensitive, no spaces allowed. Must be unique across the platform.
Discount Type Dropdown Yes Percentage (%) — Discount by percentage of the ride fare. Flat Amount — Discount by a fixed monetary amount.
Value Number Yes The discount value. For percentage: enter the percentage (e.g., 20 for 20% off). For flat: enter the amount in the zone currency (e.g., 5 for $5 off).
Min Fare Number No Minimum ride fare required to use the coupon. Prevents applying discounts to very cheap rides. Set to 0 for no minimum.
Max Discount Number No Maximum discount amount for percentage coupons. Caps the discount to prevent excessive deductions. Only applies to percentage-type coupons.
Valid From Date Yes The date when the coupon becomes active. Riders cannot use the coupon before this date. Format: YYYY-MM-DD.
Valid To Date Yes The date when the coupon expires. After this date, the coupon is automatically rejected. Format: YYYY-MM-DD.
Usage Limit Number Yes Total number of times the coupon can be redeemed across all riders. Once this limit is reached, the coupon is exhausted. Set to 0 for unlimited uses.
Per User Limit Number Yes Maximum number of times each individual rider can use this coupon. Prevents a single user from redeeming the code multiple times. Set to 0 for unlimited per user.
Status Toggle Yes Active makes the coupon redeemable. Inactive disables it without deleting. Useful for pausing a promotion temporarily.

Redemption Flow

How the system validates and applies coupons during ride booking.

Validation Steps

  1. Code exists — The system checks that the entered code matches an existing coupon in the database.
  2. Status is active — The coupon must be set to Active status. Inactive coupons are rejected.
  3. Within validity period — The current date must fall between the Valid From and Valid To dates.
  4. Usage limit not reached — Total redemptions must be below the configured Usage Limit.
  5. Per user limit not reached — The rider must not have exceeded the Per User Limit for this coupon.
  6. Minimum fare met — The ride fare (before discount) must meet or exceed the Min Fare threshold.
  7. Discount applied — If all checks pass, the discount is calculated and subtracted from the fare.

Discount Calculation

Percentage Coupon (20% off, $10 max, $8 min fare):
  Ride fare: $45.00
  Calculated discount: $45.00 × 20% = $9.00
  Max discount cap: $10.00
  Applied discount: $9.00 (under cap)
  Final fare: $45.00 - $9.00 = $36.00

Flat Coupon ($5 off, $10 min fare):
  Ride fare: $45.00
  Applied discount: $5.00
  Final fare: $45.00 - $5.00 = $40.00

Flat Coupon ($5 off, $10 min fare):
  Ride fare: $8.00
  Result: REJECTED (fare below $10 minimum)
Rider Feedback
If a coupon is rejected, the rider sees a clear error message explaining why (expired, minimum not met, usage limit reached, etc.). This transparency helps riders understand the issue and try a different code.

Best Practices

Tips for running effective coupon campaigns.

Track ROI
Monitor the total discount amount given versus the increase in rides and new user signups. A successful coupon campaign should generate more revenue than it costs in discounts.

Campaign Tips

  • Use memorable codes — Codes like WELCOME20 or SUMMER50 are easy to remember and share. Avoid random strings like X7K9M2.
  • Set per-user limits — Always set a per-user limit to prevent abuse. First-time rider coupons should have a limit of 1.
  • Combine with push notifications — Send coupon codes via Push Notifications to reach riders directly on their devices.
  • Create urgency — Short validity periods (3-7 days) create urgency and drive faster redemption.
  • Monitor usage — Check the coupon list regularly to see redemption rates. Deactivate underperforming coupons and scale successful ones.
Fraud Prevention
Monitor for coupon abuse patterns: multiple accounts using the same code, rapid successive redemptions, or accounts created solely to exploit discounts. Set conservative per-user limits for high-value coupons.
