Hourly Packages

Hourly packages let riders book vehicles for a fixed number of hours at a set price, with included base distance and charges for extra kilometers. This is ideal for tourists exploring a city, business professionals with multiple meetings, families running errands, or anyone needing a vehicle for several stops throughout the day.

How Hourly Packages Work

Understanding the hourly package model before creating packages.

Unlike per-trip ride-hailing where fares are calculated dynamically, hourly packages provide predictable, upfront pricing. The rider pays a fixed amount for a set duration and gets a base distance allowance included. Any distance beyond the allowance is charged at a per-km rate.

Package Components

  • Duration — The number of hours included in the package (e.g., 2h, 4h, 8h).
  • Price — The total upfront cost for the package.
  • Base Distance — Kilometers included in the package price (e.g., 30 km for a 2-hour package).
  • Extra Distance Charge — Per-km rate for distance exceeding the base allowance.
  • Vehicle Type — The vehicle type assigned to the package.

Pricing Example

Package:         4-Hour City Explorer
Duration:        4 hours
Price:           $60.00
Base Distance:   50 km
Extra Distance:  $1.20/km

Scenario A: Rider travels 40 km in 3 hours
  Total cost: $60.00 (within base distance)

Scenario B: Rider travels 65 km in 4 hours
  Extra km: 65 - 50 = 15 km
  Extra charge: 15 × $1.20 = $18.00
  Total cost: $60.00 + $18.00 = $78.00

Creating an Hourly Package

Follow these steps to add a new hourly rental package.

1. Navigate to Hourly Packages

Log in to the admin panel. Go to Livriko Management → Hourly Packages. You will see a list of existing packages.

2. Click "Add New Package"

Click the Add New Package button to open the package creation form.

3. Fill In Package Details

Enter the package name, select the vehicle type, set duration and pricing, configure the base distance allowance and extra distance charge rate.

4. Write a Description

Add a clear description explaining what the package includes, ideal use cases, and any restrictions. This is shown to riders when they view the package details.

5. Save and Activate

Set the Status to Active and click Save. The package will now appear in the rider app's hourly rental section.

Field Reference

Complete reference for every field on the hourly package form.

Field Type Required Description
Package Name Text Yes Display name for the package (e.g., "2-Hour City Tour", "8-Hour Full Day", "Quick errand"). Should clearly communicate the duration and purpose.
Vehicle Type Dropdown Yes The vehicle type assigned to this package. Only vehicle types with the Ride or Schedule service enabled are available for selection.
Duration Number (hours) Yes Number of hours included in the package. The rental period starts when the rider confirms pickup and ends after the specified duration. Examples: 1, 2, 4, 8.
Price Number Yes Total upfront price for the package in the zone's currency. This is the fixed amount charged to the rider at booking time.
Base Distance Number (km/miles) Yes Distance included in the package price, measured in the zone's distance unit (km or miles). Travel within this distance incurs no additional charges.
Extra Distance Charge Number Yes Per-unit charge for distance exceeding the base allowance. Charged in the zone's currency per km or mile. Set to 0 to allow unlimited distance within the time limit.
Description Textarea No Package description shown to riders. Include what is included, ideal use cases, and any restrictions or notes about the package.
Status Toggle Yes Active makes the package available for booking. Inactive hides it from the app without deleting it.

Use Cases

Common scenarios where hourly packages provide value.

Tourist City Tours

Visitors exploring a new city can book a 4-hour or 8-hour package to visit multiple attractions without worrying about per-trip costs accumulating.

Business Meetings

Professionals with multiple meetings across the city book a half-day or full-day package. The vehicle waits between stops, eliminating rebooking hassle.

Errand Running

Families or individuals running multiple errands — grocery shopping, pharmacy, bank, school pickup — save money with a 2-4 hour package.

Airport Transfers

Travelers arriving at the airport can book a package that covers the ride to the hotel, a shopping trip, and the return journey — all in one booking.

Best Practices

Tips for creating effective hourly packages.

Offer Tiered Packages
Create 3-4 packages with increasing durations (2h, 4h, 8h) at progressively better per-hour rates. This encourages riders to choose longer, higher-value packages.

Pricing Strategy

  • Per-hour rate should decrease with duration — A 2-hour package at $30/hour, 4-hour at $20/hour, and 8-hour at $15/hour incentivizes longer bookings.
  • Set base distance generously — Include enough distance that most riders stay within the allowance. This avoids bill-shock from extra charges.
  • Extra distance charge should be competitive — The per-km charge for excess distance should be reasonable to avoid rider frustration.

Naming Tips

  • Include the duration in the name: "2-Hour Quick Trip", "4-Hour Explorer", "8-Hour Full Day".
  • Use action-oriented descriptions: "Perfect for city tours", "Ideal for business meetings".
  • Avoid technical jargon — keep names simple and rider-friendly.
