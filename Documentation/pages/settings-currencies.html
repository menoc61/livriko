Currencies

Livriko supports multiple currencies for processing ride fares, rental charges, and wallet transactions. Configure the currencies available to match your operational regions and set accurate exchange rates.

Currency Fields Reference

Each currency entry in Livriko has the following configurable fields.

Field Description Example
Name Human-readable currency name displayed to users in the currency picker US Dollar, Euro
Code ISO 4217 three-letter currency code. Must be unique and follow the official standard. USD, EUR, MAD, INR
Symbol Currency symbol displayed alongside amounts in the app and admin panel $, €, £, ↓
Exchange Rate Rate relative to the platform's default currency. The default currency always has a rate of 1.0. 1.0 (default), 0.92 (EUR if USD is default)
Default Exactly one currency must be marked as the platform default. All exchange rates are calculated relative to this currency. Yes / No
Status Enable or disable the currency. Disabled currencies are hidden from the app and cannot be used for transactions. Enabled / Disabled

Adding a New Currency

Follow these steps to add a new currency to your Livriko platform.

Open the Currencies page

Log in to the admin panel and navigate to Settings → Currencies.

Click "Add New"

Click the Add New button at the top of the currencies list.

Fill in currency details

Enter the currency name (e.g., "Moroccan Dirham"), code (MAD), symbol (MAD or dh), and exchange rate relative to the default currency. If USD is the default, and 1 USD = 10 MAD, the exchange rate for MAD is 10.0.

Set status and save

Toggle the status to Enabled and click Save. The currency is now available for selection in the mobile apps and admin panel.

Exchange rate direction

The exchange rate represents how many units of this currency equal one unit of the default currency. For example, if USD is default and EUR rate is 0.92, it means 1 USD = 0.92 EUR. A higher number means the currency is weaker relative to the default.

Setting the Default Currency

The default currency is the base for all fare calculations and exchange rate conversions across the platform.

Open the Currencies page

Navigate to Settings → Currencies in the admin panel.

Select the new default

In the currencies list, locate the currency you want as default and toggle the Default option on. The previous default will be automatically unset.

Update exchange rates

After changing the default currency, you must update the exchange rates for all other currencies to reflect their value relative to the new default.

Save and verify

Click Save. Open the mobile app and verify that fares are displayed correctly in the new default currency.

Changing the default currency affects all fares

All vehicle type fares, surge pricing, and coupon values are stored in the default currency. Changing the default currency does NOT automatically convert existing fare values. You will need to manually update vehicle type pricing to reflect the new base currency.

Currency Formatting

Livriko automatically formats currency amounts based on the user's selected currency and locale.

The platform handles the following formatting rules:

  • Symbol Placement: Symbols are placed before or after the amount based on the currency's locale convention (e.g., $10.00 for USD, 10,00 € for EUR).
  • Decimal Separators: The platform uses locale-appropriate decimal and thousands separators (e.g., 1,234.56 for English vs 1.234,56 for German).
  • Decimal Places: Most currencies use 2 decimal places. Some currencies (like JPY, KWD) use 0 or 3 decimal places respectively. The platform respects these conventions.
  • Negative Amounts: Refunds and wallet deductions display with a minus sign (e.g., -$5.00).
Formatting in the mobile app

The React Native app uses the device's locale settings for number formatting. Ensure your translation files include the correct currency format strings for each language.

Exchange Rate Management

Exchange rates determine how fares are converted when a user views or pays in a non-default currency.

Exchange rates in Livriko are static — they are set manually by the admin and do not update automatically from external APIs. This gives you full control over pricing but requires periodic manual updates.

How Exchange Rates Affect Fares

  1. Fares for vehicle types are stored in the default currency (e.g., USD).
  2. When a user selects a different currency, the fare is multiplied by the exchange rate.
  3. Example: If the base fare is $10.00 (USD) and the EUR exchange rate is 0.92, the user sees €9.20.
  4. The payment is processed in the user's selected currency. The gateway handles the actual conversion.

Updating Exchange Rates

Research current rates

Use a reliable source like xe.com, Google Finance, or your payment gateway's conversion rate.

Update in Admin Panel

Go to Settings → Currencies. For each non-default currency, update the Exchange Rate field with the new value.

Save changes

Click Save. The new rates take effect immediately for all new bookings. Existing bookings retain the rate at the time of booking.

Regular updates recommended

For platforms operating in volatile currency markets, update exchange rates at least weekly. Outdated rates can result in undercharging or overcharging users, which affects trust and revenue.
