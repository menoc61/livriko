Add-Ons

Add-ons allow users to customize their ride by selecting optional extras during the booking process. Each add-on has an additional cost that is added to the ride fare.

Available Add-Ons

Livriko ships with several commonly requested add-ons. You can enable, disable, or create new add-ons from the admin panel.

Add-On Description Typical Price Available For
Child Seat Request a child safety seat for young passengers $3.00 Sedan, SUV, Van
Extra Luggage Additional luggage space for large bags or equipment $2.00 All types
Pet Friendly Request a vehicle that accepts pets $2.50 Sedan, SUV, Van

Quiet Ride Request a driver who will keep conversation to a minimum $1.00 Sedan, Luxury

Booking Flow with Add-Ons

Add-ons are selected during the ride booking process, after choosing a vehicle type and before confirming the ride:

Select Vehicle Type

The user selects a vehicle type from the vehicle selection screen (e.g., Sedan, SUV).

Choose Add-Ons

An "Add-Ons" section appears below the vehicle selection. The user can toggle on one or more available add-ons for their chosen vehicle type.

Review Fare

The fare summary updates to include add-on costs. The total fare = base fare + distance charge + add-on charges.

Confirm Booking

The user confirms the ride. The selected add-ons are sent to the driver along with the ride request.

Driver Notification

The driver sees the selected add-ons in the ride request card. They can acknowledge the add-ons (e.g., confirm they have a child seat installed).

Configuring Add-Ons in Admin

To manage add-ons in the admin panel:

Navigate to Add-Ons

Log in to the admin panel and go to Add-Ons from the sidebar.

Create or Edit

Click Add New to create a new add-on, or click an existing add-on to edit it.

Fill in Fields

Enter the name, description, price, upload an icon, and set the status to Active.

Configure Availability

Select which vehicle types this add-on is available for. For example, "Child Seat" might only be available for Sedan and SUV.

Save

Click Save to apply changes. The add-on will appear in the mobile apps on the next API call.

Add-On Display in the App

In the User app, add-ons appear as toggleable chips or checkboxes on the vehicle selection screen. Each add-on shows its name, description, and price. Users can select multiple add-ons, and the fare summary updates in real-time to reflect the total add-on cost.

In the Driver app, selected add-ons are displayed in the ride request card so the driver knows what to prepare before arriving at the pickup location. For example, if a "Child Seat" add-on is selected, the driver knows to install the seat before the trip.

Add-On Pricing Strategy

When setting add-on prices, consider the following factors:

  • Cost Recovery: Ensure the price covers the actual cost of providing the add-on (e.g., child seat maintenance, pet cleaning)
  • Market Rates: Research what competitors charge for similar add-ons in your market
  • Perceived Value: Users are willing to pay more for convenience add-ons like Priority Pickup
  • Minimum Threshold: Set prices low enough to encourage usage but high enough to remain profitable

Add-On Availability

Add-on availability varies by vehicle type. For example, the "Wheelchair Accessible" add-on should only be available for vehicles in your accessible fleet. Configure this in the add-on settings to ensure users only see relevant options for their selected vehicle type.

Driver Acknowledgment

When a ride with add-ons is accepted, the driver sees a summary of selected add-ons in the ride request card. The driver should acknowledge that they can fulfill the add-on requirements (e.g., confirm they have a child seat installed, confirm the vehicle accepts pets). This acknowledgment is logged in the system for accountability and dispute resolution.

If a driver cannot fulfill a selected add-on, they can decline the ride request. The system will then match the rider with another available driver who can accommodate the add-on requirements. This ensures riders always get the experience they paid for.

Add-On Revenue Tracking

The admin panel tracks add-on revenue separately from base fares. You can view add-on performance metrics including total add-on revenue, most popular add-ons, and revenue per add-on type. Use this data to optimize your add-on offerings and pricing strategy.

Revenue Opportunity

Add-ons are a significant revenue opportunity. Consider adding add-ons like "Priority Pickup" or "Extra Luggage" that users are willing to pay a premium for. Monitor which add-ons are most popular and adjust pricing accordingly. Popular add-ons can generate 10-20% of total ride revenue.
