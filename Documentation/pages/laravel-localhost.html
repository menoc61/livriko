Localhost Configuration

This guide walks you through setting up a complete local development environment for Livriko. By the end, you'll have PHP, Composer, MySQL, Node.js, and Redis running on your machine — ready for the Livriko installation.

Prerequisites Check
Before proceeding, confirm you've reviewed the Prerequisites page and understand the minimum version requirements for PHP, MySQL, and Node.js.

Step 1: Install PHP 8.2+

PHP is the backbone of Livriko's Laravel backend. You need version 8.2 or higher with all required extensions enabled.

Ubuntu / Debian

Use the Ondrej PPA to install the latest PHP version:

# Add the Ondrej PHP repository
sudo add-apt-repository ppa:ondrej/php -y
sudo apt update

# Install PHP 8.2 and required extensions
sudo apt install -y php8.2 php8.2-cli php8.2-common php8.2-mysql \
  php8.2-xml php8.2-mbstring php8.2-curl php8.2-zip php8.2-gd \
  php8.2-bcmath php8.2-redis php8.2-intl php8.2-readline

# Verify PHP version
php -v

macOS

Use Homebrew to install PHP:

# Install Homebrew if not already installed
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Install PHP
brew install php

# Verify
php -v

Windows

Download the latest PHP from windows.php.net or use Laravel Herd which includes PHP pre-configured.

Version Matters
Livriko requires PHP 8.2 or higher. Running an older version will cause composer install to fail with dependency resolution errors. Always verify with php -v.

Step 2: Install Composer

Composer is the PHP dependency manager used by Laravel. It reads the composer.json file and installs all required PHP packages.

# Download and install Composer globally
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer

# Verify installation
composer --version
# Expected: Composer version 2.7.x 2024-xx-xx
Memory Limit
If you encounter memory limit errors during composer install, increase the memory limit in php.ini: memory_limit = 512M. This is especially important on shared hosting or VPS with limited RAM.

Step 3: Install MySQL 8.0

Livriko uses MySQL 8.0 as its primary database. You need both the MySQL server and client installed.

Ubuntu / Debian

# Install MySQL server
sudo apt install -y mysql-server

# Start and enable MySQL
sudo systemctl start mysql
sudo systemctl enable mysql

# Secure the installation
sudo mysql_secure_installation

# Log in to MySQL
sudo mysql -u root -p

# Create a database for Livriko
CREATE DATABASE livriko_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;

macOS

# Install MySQL via Homebrew
brew install mysql

# Start MySQL
brew services start mysql

# Secure the installation
mysql_secure_installation

# Create Livriko database
mysql -u root -p -e "CREATE DATABASE livriko_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

Windows (XAMPP)

If you're using XAMPP, MySQL is included. Start it from the XAMPP Control Panel by clicking Start next to MySQL. Access phpMyAdmin at http://localhost/phpmyadmin to create the database via the web interface.

Step 4: Install Node.js 20+

Node.js is required for compiling frontend assets and for building the React Native mobile applications. We recommend version 20.x (LTS).

Using NVM (Recommended)

NVM (Node Version Manager) lets you install and switch between multiple Node.js versions:

# Install NVM
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash

# Restart your terminal, then install Node.js 20
nvm install 20
nvm use 20

# Verify
node -v    # v20.x.x
npm -v     # 10.x.x

Direct Download

Alternatively, download the LTS version directly from nodejs.org. The installer includes npm automatically.

Step 5: Install Redis Optional

Redis is an in-memory data store that significantly improves Livriko's performance for caching, session management, and background job processing. While optional for local development, it's recommended to install it now so your development environment mirrors production.

# Ubuntu / Debian
sudo apt install -y redis-server
sudo systemctl start redis-server
sudo systemctl enable redis-server

# macOS
brew install redis
brew services start redis

# Verify Redis is running
redis-cli ping
# Expected response: PONG
Redis Configuration in Livriko
To use Redis, update your .env file after installation: set CACHE_DRIVER=redis, QUEUE_CONNECTION=redis, and SESSION_DRIVER=redis. This is not required for initial setup but recommended for a production-like development environment.

Step 6: Verify Your Environment

Run the following commands to confirm all tools are installed and accessible:

# PHP version check
php -v

# PHP extensions check
php -m | grep -iE "ctype|curl|dom|fileinfo|filter|hash|mbstring|openssl|pdo|session|tokenizer|xml"

# Composer check
composer --version

# Node.js check
node -v
npm -v

# MySQL check
mysql --version

# Redis check (optional)
redis-cli ping
Command Expected Output If Missing
php -v PHP 8.2.x or higher Install PHP via Ondrej PPA or Homebrew
composer --version Composer version 2.x Run the Composer installer script
node -v v20.x.x Install via NVM or nodejs.org
mysql --version mysql Ver 8.x Install MySQL server
Common Issues
  • "php: command not found" — PHP is not in your PATH. Restart your terminal after installation.
  • "composer: command not found" — Composer was installed locally, not globally. Use php composer.phar instead or move it to /usr/local/bin/.
  • "Access denied for user 'root'" — MySQL root password is set. Use mysql -u root -p and enter your password.
