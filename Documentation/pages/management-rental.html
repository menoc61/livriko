Rental Vehicles

Rental vehicles allow riders to rent vehicles for a specific duration — by the hour, day, or week. Configure the vehicles available for rental, set pricing tiers, manage security deposits, and control zone availability. The rental service is a revenue-generating add-on that complements standard ride-hailing.

How Rental Works

The rental flow differs from standard ride-hailing in several key ways.

  • Duration-based pricing — Instead of per-km/per-minute fares, rentals charge by the hour, day, or week.
  • Security deposit — A refundable deposit is collected at booking time to cover potential damages.
  • Vehicle handoff — The driver delivers the vehicle to the rider's location or a designated pickup point.
  • Insurance options — Optional insurance packages can be offered to riders for additional protection.
  • Zone availability — Rental vehicles can be limited to specific zones where they are available.

Adding a Rental Vehicle

Follow these steps to add a new rental vehicle to your platform.

1. Navigate to Rental Vehicles

Log in to the admin panel. Go to Livriko Management → Rental Vehicles. You will see a list of existing rental vehicles.

2. Click "Add New Vehicle"

Click the Add New Vehicle button. The rental vehicle creation form opens with all configurable fields.

3. Upload Vehicle Image

Upload a clear photo of the rental vehicle. This image is displayed to riders when they browse available rental options. Use a high-resolution photo (minimum 800×600px) with good lighting.

4. Configure Pricing & Deposit

Set the hourly, daily, and weekly rental rates. Configure the security deposit amount that will be held on the rider's payment method during the rental period.

5. Assign to Zones

Select the zones where this rental vehicle is available. Only riders in selected zones will see this vehicle in the rental section.

6. Save and Activate

Set the Status to Active and click Save. The rental vehicle will now appear in the rider app's rental section.

Field Reference

Complete reference for every field on the rental vehicle form.

Field Type Required Description
Vehicle Dropdown Yes Select the base vehicle type from the list of configured vehicle types. This links the rental vehicle to a vehicle type for map icons and basic configuration.
Name Text Yes Display name for the rental vehicle (e.g., "Toyota Corolla", "Honda Civic", "BMW 3 Series"). This name is shown to riders in the rental listing.
Image File upload Yes Photo of the rental vehicle displayed in the rider app. Use a clear, well-lit photo showing the vehicle's exterior. Minimum 800×600px.
Description Textarea No Brief description of the vehicle features, specifications, and included amenities (e.g., "5 seats, automatic, AC, Bluetooth, 2 bags capacity").
Price Per Hour Number Yes Rental rate per hour. Used when riders book the vehicle for hourly rentals. Set to 0 if hourly rentals are not offered.
Price Per Day Number Yes Rental rate per 24-hour period. Typically lower than 24 × hourly rate to incentivize longer rentals.
Price Per Week Number No Rental rate per 7-day period. Offer the best value for long-term rentals. Leave at 0 if weekly rentals are not offered.
Security Deposit Number Yes Refundable deposit collected at booking time via the rider's payment method. Returned after the vehicle is returned in good condition. Set to 0 if no deposit is required.
Status Toggle Yes Active makes the rental vehicle available for bookings. Inactive hides it from the rental section without deleting it.

Zone Availability

Control where rental vehicles can be booked and returned.

When configuring rental vehicles, you assign them to specific zones. This ensures that:

  • Only riders in enabled zones can see and book the rental vehicle.
  • Pickup and return are restricted to the assigned zone boundaries.
  • Inventory management is simplified by limiting vehicles to areas where they are physically available.
Multi-Zone Rentals
A single rental vehicle can be assigned to multiple zones. This is useful for vehicles available across a city or region. However, ensure the vehicle is physically present or deployable in all assigned zones.

Insurance Options

Offer optional insurance packages to protect riders during rental periods.

Insurance Types

  • Basic Coverage — Covers third-party liability. Typically included in the base rental price or offered at a small daily fee.
  • Comprehensive Coverage — Covers damage to the rental vehicle itself (collision, theft, vandalism). Higher daily fee but provides peace of mind.
  • Zero Deductible — Eliminates the rider's deductible in case of a claim. Premium pricing option for risk-averse renters.

Configuring Insurance

  1. Navigate to Livriko Management → Rental Vehicles.
  2. Edit the rental vehicle you want to add insurance to.
  3. In the insurance section, add insurance packages with name, daily rate, and coverage description.
  4. Save the changes. Insurance options will now appear as add-ons during the rental booking flow.
Legal Compliance
Insurance requirements vary by jurisdiction. Consult local regulations to determine mandatory insurance coverage for vehicle rentals in your operating region. Some areas require minimum liability coverage by law.
