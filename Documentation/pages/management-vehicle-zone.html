Vehicle Zone & Surge Pricing

Vehicle Zone Pricing is where you define the exact fare structure for each vehicle type within each zone. This is the core pricing engine of your Livriko platform — it determines how much riders pay and how much drivers earn per trip. Configure base fares, per-km rates, per-minute rates, minimum fares, and per-zone surge multipliers.

Why Per-Zone Pricing?

Different areas have different market conditions that require tailored pricing.

  • Urban vs. suburban — City centers typically have higher demand and can support higher fares than suburban or rural areas.
  • Competitive markets — In areas with strong competition, lower fares may be necessary to attract riders.
  • Operating costs — Fuel, tolls, and vehicle maintenance costs vary by region, affecting driver profitability.
  • Currency differences — Multi-country deployments require zone-specific pricing in local currencies.
Independent Configuration
Each vehicle type + zone combination is configured independently. This means a "Comfort" sedan can have a base fare of $5 in Paris but $3 in Lyon, with different per-km and per-minute rates for each city.

Configuring Vehicle Zone Pricing

Follow these steps to set up pricing for a vehicle type in a zone.

1. Navigate to Vehicle Zone Pricing

Log in to the admin panel. Go to Livriko Management → Vehicle Zone Pricing. You will see a table of all existing vehicle-zone pricing configurations.

2. Select Zone and Vehicle Type

Choose the zone and vehicle type from the dropdown menus. Each combination creates a unique pricing record. If a pricing record already exists for this combination, you will be taken to edit it.

3. Set Base Fare and Rates

Configure the base fare (starting price), per-km rate, per-minute rate, and minimum fare. These four values form the foundation of fare calculation for this vehicle type in this zone.

4. Configure Surge Multiplier

Set the default surge multiplier for this vehicle type in this zone. This is the base multiplier applied during surge periods. Time-based surge rules (from Surge Pricing) can override or adjust this value.

5. Save

Click Save to apply the pricing configuration. The new rates take effect immediately for new ride requests. Ongoing rides are not affected by pricing changes.

Field Reference

Complete reference for every pricing field.

Field Type Required Description
Zone Dropdown Yes The geographic zone where this pricing applies. Must be an existing, active zone. The zone determines the currency and distance unit used for fare calculations.
Vehicle Type Dropdown Yes The vehicle type this pricing applies to. Must be an existing, active vehicle type. Each vehicle type can have different pricing in the same zone.
Base Fare Number Yes The starting fare charged at the beginning of every trip, regardless of distance or duration. This is the minimum amount before any distance or time charges. Displayed to riders as the "starting at" price.
Per KM Rate Number Yes Price charged per kilometer (or mile, based on zone distance type) traveled. Multiplied by the total trip distance to calculate the distance component of the fare.
Per Minute Rate Number Yes Price charged per minute of trip duration. Multiplied by the total trip time (including waiting time in traffic) to calculate the time component of the fare.
Minimum Fare Number Yes The minimum amount a rider will be charged for a trip. If the calculated fare (base + distance + time) is less than the minimum fare, the minimum fare is charged instead. Prevents very short trips from being unprofitable.
Surge Multiplier Number No Default surge multiplier for this vehicle type in this zone. Applied to the total fare during surge periods. Set to 1.0 for no surge, 1.5 for 50% increase, etc. Time-based surge rules can override this value.

Fare Calculation Formula

How the platform calculates the total fare for a ride.

Step 1: Calculate base components
  Distance Charge = Trip Distance × Per KM Rate
  Time Charge     = Trip Duration × Per Minute Rate

Step 2: Calculate subtotal
  Subtotal = Base Fare + Distance Charge + Time Charge

Step 3: Apply minimum fare
  If Subtotal < Minimum Fare → Subtotal = Minimum Fare

Step 4: Apply surge (if active)
  Surge Amount = Subtotal × (Surge Multiplier - 1)
  Total Fare   = Subtotal + Surge Amount

Step 5: Apply commission and tax
  Commission  = Total Fare × Commission %
  Tax         = Total Fare × Tax %

Step 6: Calculate driver earnings
  Driver Earnings = Total Fare - Commission + Tax

Worked Example

Vehicle:    Comfort
Zone:       Paris
Base Fare:  $3.00
Per KM:     $0.80
Per Minute: $0.15
Minimum:    $5.00
Commission: 20%
Tax:        10%
Surge:      None (1.0x)

Trip: 12 km, 20 minutes

Distance Charge: 12 × $0.80 = $9.60
Time Charge:     20 × $0.15 = $3.00
Subtotal:        $3.00 + $9.60 + $3.00 = $15.60
Minimum Check:   $15.60 > $5.00 ✓ (minimum not applied)
Total Fare:      $15.60
Commission:      $15.60 × 0.20 = $3.12
Tax:             $15.60 × 0.10 = $1.56
Driver Earnings: $15.60 - $3.12 + $1.56 = $14.04

Surge Pricing Per Zone

How surge multipliers interact with per-zone pricing.

Each vehicle-zone pricing record includes a default surge multiplier. This multiplier interacts with the time-based surge rules configured under Surge Pricing.

Surge Priority

  • Time-based surge rules take precedence over the default per-zone surge multiplier.
  • If a time-based surge rule is active, its multiplier replaces the per-zone default.
  • If no time-based rule is active, the per-zone surge multiplier is used (typically 1.0x = no surge).
  • When multiple time-based rules overlap, the highest applicable multiplier is used.
Zone-Specific Surge
The per-zone surge multiplier allows you to set different surge levels for different areas. For example, you might set a 1.5x default surge for the downtown zone but only 1.2x for suburban zones, reflecting different demand patterns.

Pricing Strategies

Recommended approaches for setting competitive and profitable fares.

Market Research

Research competitor pricing in your market. Set fares within 10-15% of major competitors to remain competitive while maintaining margins.

Tier Differentiation

Create clear price gaps between vehicle tiers. Economy should be 30-40% cheaper than Comfort, which should be 30-40% cheaper than Premium.

Minimum Fare Floor

Set minimum fares high enough to cover driver costs for short trips. A $5 minimum ensures even a 1 km trip is worth the driver's time.

Commission Balance

Keep commissions between 15-25%. Higher commissions increase revenue per trip but may reduce driver retention and increase turnover.
