Installation Overview

Livriko is a complete mobility platform consisting of three tightly integrated components. This page provides an overview of the architecture, the available installation methods, the full module system, and the recommended setup order.

Platform Architecture

Livriko is built on three components that communicate via RESTful APIs and real-time WebSocket connections.

1
Laravel 12 · PHP 8.2

Backend API + Admin Panel

The server-side core handling all business logic, authentication, ride management, payments, fleet operations, and real-time communication. Includes a full admin dashboard for platform management.

2
React Native 0.82.1

User App

The passenger-facing mobile application with Google Maps integration, multiple payment options, ride booking and scheduling, real-time driver tracking, ride history, and in-app chat.

3
React Native 0.82.1

Driver App

The driver-facing mobile application with turn-by-turn navigation, earnings dashboard, background location tracking, online/offline toggle, ride acceptance, and SOS emergency features.

Communication Layer
All three components communicate via RESTful APIs with Laravel Sanctum authentication. Real-time features (ride status updates, driver location pings, chat messages) use Laravel Reverb WebSockets, while push notifications are delivered through Firebase Cloud Messaging (FCM).

Installation Methods

The Livriko Backend API can be installed using one of two methods, depending on your comfort level with the command line.

GUI Installer

A web-based installation wizard with a step-by-step interface. Handles environment checks, database configuration, and initial setup automatically. Ideal for beginners and non-technical users.

Recommended for Beginners

CLI Installation

Command-line installation using terminal commands and Composer. Gives you full control over every step. Recommended for developers comfortable with the terminal and server administration.

Recommended for Developers

What's Included — Module System

Livriko is built on a modular architecture. The platform ships with 20 business modules that can be individually enabled or disabled. Some modules are active by default; others are disabled until you're ready to use them.

Enabling Modules
Disabled modules can be enabled at any time through the admin panel under Platform Settings → Modules. Enabling a module will add its database tables (via migrations) and make its features available in the admin panel and mobile apps.

Installation Flow

Follow these steps in order to go from zero to a fully functional Livriko deployment. Each step depends on the previous one — do not skip ahead.

Backend First
You must install the Backend API first. The mobile apps depend on the backend for all data, authentication, real-time updates, and push notifications. Installing apps before the backend will result in connection errors.

1. Set Up Local Environment

Install PHP 8.2+, Composer, MySQL 8.0, and Node.js 20+. See the Localhost Configuration guide for platform-specific instructions.

2. Install the Backend API

Choose the GUI installer or CLI installation. This sets up the server, database, admin panel, and all core modules.

3. Configure Environment Variables

Edit the .env file with your database credentials, application URL, Firebase configuration, and payment gateway keys.

4. Set Up the User App

Install React Native, configure the API endpoint, and build the passenger mobile application for Android and/or iOS.

App Installation →

5. Set Up the Driver App

Configure the driver application with navigation, background location tracking, and earnings dashboard.

Create Driver App →

6. Configure Firebase

Set up Firebase for push notifications, real-time messaging, and social login authentication.

Firebase Setup →

7. Enable Payment Gateways

Configure Stripe, PayPal, Razorpay, or other payment providers for your target market.

Payment Gateways →

8. Deploy to Production

Deploy the backend to cPanel or VPS, configure SSL certificates, and release the mobile apps to the App Store and Google Play.

Deployment →

Quick Start Commands

For reference, here are the essential commands to get Livriko running locally:

Backend API

# Clone the repository
git clone https://github.com/HitechFacilitator/livriko.git
cd livriko/Taxido_laravel

# Install PHP dependencies
composer install

# Configure environment
cp .env.example .env
php artisan key:generate

# Set up database (edit .env with your credentials first)
php artisan migrate --seed

# Create storage symlink
php artisan storage:link

# Start development server
php artisan serve

User App

cd livriko/Taxido_user
npm install
npm run android    # or: npm run ios

Driver App

cd livriko/Taxido_driver
npm install
npm run android    # or: npm run ios

After Installation

Once the installation is complete, you'll need to configure the following to make Livriko fully operational:

Application URL

Update APP_URL in your .env file to match your domain or local development URL. This affects email links, API responses, and storage URLs.

Firebase Configuration

Set up a Firebase project for push notifications, real-time messaging, and optional social login. See the Firebase setup guide.

Payment Gateways

Configure at least one payment gateway (Stripe or PayPal) to accept digital payments. See the Payment Gateways guide.

You're Ready
With the installation complete, you can now access the admin panel at http://localhost:8000/admin, log in with your admin credentials, and start configuring your platform.
