Prerequisites

Before installing the Livriko backend, ensure your server environment meets all the requirements listed on this page. Missing any prerequisite may cause installation failures, runtime errors, or degraded performance. We recommend reading this page thoroughly before proceeding.

Important
Livriko runs on Laravel 12, which requires PHP 8.2 or higher. Older PHP versions will not work. Always verify your PHP version before starting the installation.

System Requirements

The following table lists all required software and their minimum versions. Ensure every item is installed and up to date.

Composer 2.0 2.7+ PHP dependency manager. Install from getcomposer.org.
MySQL 8.0 8.0+ Primary database engine. MariaDB 10.3+ is also compatible.
Node.js 20.x 20.x LTS Required for frontend asset compilation and React Native apps.
NPM / Yarn Latest Latest Bundled with Node.js. Used for JavaScript dependency management.
Laravel 12.x 12.x The PHP framework powering Livriko's backend API.

Required PHP Extensions

Livriko and Laravel 12 depend on a specific set of PHP extensions. These must all be enabled in your php.ini configuration. Missing extensions will cause the installation wizard to fail or produce runtime errors.

Checking Extensions
Run php -m in your terminal to see all currently enabled extensions. Compare the output against the list below to identify any missing ones.
Extension Purpose in Livriko
Ctype Character type checking — used for input validation and string sanitization across the platform.
cURL HTTP client for outgoing API requests — essential for payment gateway integrations (Stripe, PayPal), SMS services, and Firebase communication.
DOM Document Object Model manipulation — required by Laravel's XML-based configuration and Blade template engine.
Fileinfo File type detection — used for validating uploaded files (profile photos, vehicle images, documents).
Filter Input filtering and data sanitization — used throughout Livriko for securing user input.
Hash Cryptographic hashing — required for password hashing, API token generation, and data integrity checks.
Mbstring Multi-byte string handling — critical for multi-language support, including Arabic, Chinese, and other non-Latin scripts.
OpenSSL Encryption and SSL/TLS — required for secure API communication, payment processing, and encrypted sessions.
PCRE Regular expression support — used for URL routing, input validation, and pattern matching throughout the application.
PDO PHP Data Objects — the database abstraction layer that Laravel uses to communicate with MySQL.
PDO MySQL MySQL database driver — the specific PDO driver for MySQL connectivity.
Session Session management — required for user authentication and maintaining logged-in state.
Tokenizer PHP tokenizer — used by Laravel for parsing and compiling Blade templates.
XML XML parsing and generation — required for SOAP APIs, RSS feeds, and some payment gateway integrations.

To enable a missing extension, uncomment it in your php.ini file and restart your web server:

; Example: Enable required extensions in php.ini
extension=ctype
extension=curl
extension=dom
extension=fileinfo
extension=filter
extension=hash
extension=mbstring
extension=openssl
extension=pdo
extension=pdo_mysql
extension=session
extension=tokenizer
extension=xml
Restart Required
After enabling or disabling any PHP extension, you must restart your web server (Apache or Nginx) for the changes to take effect. On Linux, use sudo systemctl restart apache2 or sudo systemctl restart nginx.

Server Requirements

Livriko can run on both Apache and Nginx web servers. The server must be configured to handle URL rewriting so that Laravel's routing works correctly.

Apache

Ensure mod_rewrite is enabled. The .htaccess file in Laravel's public/ directory handles URL rewriting automatically. Enable it with sudo a2enmod rewrite and restart Apache.

Nginx

Configure a try_files directive in your server block to route all requests to index.php. Nginx requires PHP-FPM to process PHP files. See the VPS Nginx deployment guide for a complete configuration.

PHP Configuration Recommendations

For optimal performance and compatibility, ensure the following PHP settings in your php.ini:

  • memory_limit = 256M — Laravel and its modules require sufficient memory for complex operations.
  • upload_max_filesize = 64M — Allows uploading larger profile photos and vehicle images.
  • post_max_size = 64M — Should be equal to or greater than upload_max_filesize.
  • max_execution_time = 300 — Prevents timeout during migrations and heavy operations.
  • max_input_time = 300 — Allows sufficient time for large form submissions.

Optional Services

While not strictly required, the following services are strongly recommended for production deployments to ensure optimal performance, reliability, and real-time capabilities.

Redis

An in-memory data store used for session caching, queue job management, and broadcasting. Using Redis instead of the default file driver significantly improves performance under load. Install Redis and set CACHE_DRIVER=redis, QUEUE_CONNECTION=redis, and SESSION_DRIVER=redis in your .env file.

Laravel Reverb

Laravel Reverb provides WebSocket connectivity for real-time features like live driver location tracking, ride status updates, and instant chat messages between riders and drivers. Reverb runs as a separate process and should be managed with Supervisor in production. See the Firebase overview for configuration details.

Mail Service

Livriko uses email for account verification, password resets, and transaction receipts. Configure an SMTP provider (Mailtrap for development, SendGrid or AWS SES for production) in your .env file under the MAIL_* settings.

Quick Verification Checklist

Run these commands in your terminal to verify all prerequisites are met before proceeding with the installation.

# Check PHP version (must be 8.2+)
php -v

# Check required PHP extensions
php -m | grep -iE "ctype|curl|dom|fileinfo|filter|hash|mbstring|openssl|pdo|session|tokenizer|xml"

# Check Composer
composer --version

# Check Node.js and NPM
node -v
npm -v

# Check MySQL
mysql --version

# Check Git
git --version
Do Not Skip Prerequisites
If any of the above commands return an error or show an older version than required, you must install or update that component before proceeding. Skipping prerequisites will lead to installation failures and hard-to-debug runtime errors.
