Settings

The general settings page contains the core configuration for your Livriko platform. These settings control app behavior, integrations, branding, and system defaults.

General Tab

Configure the basic application settings:

Field Description
App Name Your platform name displayed throughout the app and admin panel
App Logo Upload your brand logo (recommended: 200x50px PNG with transparent background)
Privacy Policy URL Link to your privacy policy page (shown in the app)
Terms URL Link to your terms of service page
App Store URL Link to your iOS app on the Apple App Store
Play Store URL Link to your Android app on Google Play

Appearance Tab

Customize the look and feel of your Livriko platform:

Field Description
Primary Color Main brand color used for buttons, headers, and accents (use the color picker)
Sidebar Color Type Choose between Solid (single color) or Gradient (two-color gradient)
Gradient Colors If using gradient, set the start and end colors for the sidebar
Font Family Font used in the admin panel (e.g., Inter, Roboto, Open Sans)
Front Font Family Font used in the mobile apps and landing page
Tip

Choose a primary color that matches your brand identity. This color will be used consistently across the admin panel, mobile apps, and landing page for a cohesive experience.

Activations Tab

Toggle features on or off for your platform:

Feature Description
Wallet System Enable/disable in-app wallet for drivers and riders
Coupon System Enable/disable discount coupon functionality
Surge Pricing Enable/disable dynamic pricing based on demand
Rental Vehicles Enable/disable vehicle rental feature
Hourly Packages Enable/disable hourly ride packages
Fleet Manager Enable/disable fleet management features
SOS Button Enable/disable emergency SOS button in the app

Email Configuration

Configure email sending for notifications and transactional emails:

Field Description
Mailer Email transport: Sendmail, SMTP, or Mailgun
Host SMTP server hostname (e.g., smtp.gmail.com)
Port SMTP port (typically 587 for TLS, 465 for SSL)
Username SMTP authentication username
Password SMTP authentication password
Encryption TLS or SSL encryption type
From Address Sender email address (e.g., noreply@yourdomain.com)
Note

Changes to mail settings require clearing the config cache. Run php artisan config:clear after making changes to email configuration.

Google reCAPTCHA

Protect your admin panel and API endpoints from spam and abuse with Google reCAPTCHA:

Create reCAPTCHA Keys

Visit Google reCAPTCHA Admin and create new keys. Choose reCAPTCHA v2 (checkbox) or v3 (invisible).

Add Keys to Livriko

Enter the Site Key and Secret Key in the reCAPTCHA settings section.

Test the Integration

Verify reCAPTCHA appears on login forms and registration pages.

Social Login Configuration

Configure social login providers for user authentication:

Provider Required Fields Setup Guide
Google Client ID, Client Secret Social Login Guide
Facebook Client ID, Client Secret Social Login Guide
Apple Client ID, Team ID, Key ID Social Login Guide

Maintenance Mode

Enable maintenance mode to take the platform offline for updates:

Enable Maintenance Mode

Toggle the "Maintenance Mode" switch. All users will see a maintenance page.

Set Custom Message

Enter a custom message to display during maintenance (e.g., "We're upgrading. Back in 30 minutes.").

Important

Remember to disable maintenance mode after completing your updates. Users will not be able to access the platform while maintenance mode is active.
