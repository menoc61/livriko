Google Maps

Google Maps is required for map display, geolocation, route calculation, and driver tracking in both the User and Driver apps. Follow these steps to configure Google Maps for Livriko.

Create a Google Cloud Project

Open Google Cloud Console

Go to console.cloud.google.com and sign in with your Google account.

Create New Project

Click Select a project → New Project. Enter a project name (e.g., "Livriko Maps") and click Create.

Select the Project

Ensure the newly created project is selected in the project dropdown at the top of the console.

Enable Required APIs

Livriko requires several Google Maps APIs. Enable each one in the APIs & Services → Library section.

API Purpose Required
Maps SDK for Android Map display on Android devices Yes
Maps SDK for iOS Map display on iOS devices Yes
Geocoding API Convert addresses to coordinates and vice versa Yes
Directions API Route calculation, turn-by-turn directions, and ETA Yes
Distance Matrix API Calculate distances and travel times between multiple points Yes
Places API Place search, autocomplete, and place details Yes
Maps JavaScript API Map display on the admin panel web interface Yes

Enabling APIs

Go to APIs & Services → Library, search for each API name, click on it, and then click Enable. Repeat for all seven APIs listed above.

Create and Restrict API Key

Create a single API key that will be shared across both apps and the admin panel, then restrict it for security.

Create API Key

Go to APIs & Services → Credentials. Click Create Credentials → API key. Copy the generated key immediately.

Add Application Restrictions

Click on the newly created key. Under Application restrictions, add your Android package name + SHA-1 fingerprint and your iOS bundle ID.

Add API Restrictions

Under API restrictions, select Restrict key and choose only the 7 APIs listed above. This prevents abuse if the key is exposed.

Save and Distribute

Click Save. Use this same key in both apps and the admin panel.

Never Leave an API Key Unrestricted

Unrestricted keys can be abused by anyone, leading to unexpected charges on your Google Cloud account. Always apply both application and API restrictions.

Configure Key in Apps

Add the API key to both apps in three places:

1. React Native Config

// src/config/config.js (both User and Driver apps)
export const GOOGLE_MAPS_API_KEY = 'AIzaSy...YOUR_KEY';

2. Android Manifest

<!-- android/app/src/main/AndroidManifest.xml -->
<application>
    <meta-data
        android:name="com.google.android.geo.API_KEY"
        android:value="YOUR_GOOGLE_MAPS_API_KEY"/>
</application>

3. iOS AppDelegate

// ios/LivrikoUser/AppDelegate.m  (or AppDelegate.swift)
// For Objective-C:
#import <GoogleMaps/GoogleMaps.h>

- (BOOL)application:(UIApplication *)application
    didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
  [GMSServices provideAPIKey:@"YOUR_GOOGLE_MAPS_API_KEY"];
  // ... rest of initialization
  return YES;
}

// For Swift:
import GoogleMaps
GMSServices.provideAPIKey("YOUR_GOOGLE_MAPS_API_KEY")

Configure in Admin Panel

The admin panel uses Google Maps for the dashboard map, zone visualization, and driver location tracking.

  1. Log in to the admin panel at https://yourdomain.com/admin
  2. Go to Settings → Google Maps
  3. Enter your Google Maps API key
  4. Click Save

Map Customization

Customize the map appearance in the apps through the admin panel or config files:

Setting Location Description
Map Style Admin → Settings → Google Maps Custom JSON map style (day/night theme, colors, labels)
Default Zoom src/config/config.js Initial zoom level when the map loads
Marker Icons src/assets/images/ Custom marker images for pickup, destination, and driver location
Polyline Color src/components/map/RoutePolyline.js Route line color and width on the map

Testing Your Maps Configuration

After configuring the API key in all locations, verify that maps load correctly in both apps:

Test User App

Open the User App. The home screen should display a Google Map centered on the user's current location. Verify the map tiles load and the location marker appears.

Test Driver App

Open the Driver App. The home screen map should load with the online/offline toggle. Verify driver location updates appear in real-time.

Test Route Drawing

Request a ride in the User App and verify that the route polyline draws correctly between pickup and destination. Confirm ETA and distance are displayed.

Check Console for Errors

If the map does not load, check the React Native console and logcat (Android) or Xcode console (iOS) for API key errors or billing alerts.

Billing Warning

Google Maps APIs require a billing account. Google provides $200/month free credit, which covers most small to medium deployments. Monitor your usage in the Google Cloud Console → Billing to avoid unexpected charges. Set up budget alerts to get notified before exceeding free tier limits.
