Coupons

Coupons allow you to offer discounts to users on rides, rentals, and deliveries. You can create percentage-based or fixed-amount coupons with various restrictions and expiry rules.

Coupon Types

Livriko supports two primary coupon discount types, each with different configuration options.

Type Description Example
Percentage Discount Discount calculated as a percentage of the ride fare. Can include a maximum discount cap. 20% off, max $15 discount
Fixed Amount A flat discount amount deducted from the ride fare regardless of the total. $10 off any ride

Creating a Coupon

Follow these steps to create a new coupon in the admin panel:

Navigate to Coupons

Log in to the admin panel and go to Coupons from the sidebar menu.

Click Add New

Click the Add New button to open the coupon creation form.

Fill in Coupon Details

Enter all required fields — code, type, value, restrictions, and validity period. See the full field reference below.

Save the Coupon

Click Save. The coupon is now active and can be applied by users in the mobile app.

Coupon Configuration Fields

Field Description Example
Code The code users enter to apply the coupon (case-insensitive) WELCOME20
Type Percentage or Fixed amount Percentage
Value The discount value (e.g., 20 for 20% off or $20 off) 20
Max Discount Cap the discount amount (for percentage coupons only) $15
Minimum Fare Minimum ride fare required to use the coupon $10
Usage Limit Total number of times this coupon can be used globally 1000 (empty = unlimited)
Per User Limit Maximum uses per individual user 1
Start Date Date the coupon becomes active 2025-01-01
End Date Date the coupon expires 2025-12-31
Services Which services this coupon applies to Ride, Rental, Delivery
Vehicle Types Which vehicle types this coupon applies to Sedan, SUV
Zones Which zones this coupon is valid in City Center, Airport
Status Enable or disable the coupon Active

User App — Apply Coupon Screen

Users can apply coupons during the ride booking process. The flow is:

  1. Enter pickup and destination locations
  2. Select a vehicle type
  3. On the fare summary screen, tap "Apply Coupon"
  4. Enter the coupon code in the text field and tap Apply
  5. If valid, the discount is reflected in the fare total immediately
  6. If invalid, an error message explains the reason (expired, minimum fare not met, etc.)

Driver App — Coupon Display

When a user applies a coupon to a ride, the driver sees the discount reflected in the ride details. The driver's earnings are calculated on the original fare before the coupon discount. The coupon discount is absorbed by the platform, not the driver.

Expiry Handling

Coupons have built-in expiry management:

  • Automatic Expiry: Coupons automatically become inactive after their end date
  • Usage Limit Reached: When the global usage limit is reached, the coupon is deactivated
  • Per User Limit: Users who have exhausted their per-user limit see an error message
  • Expired Coupon Error: Users attempting to apply an expired coupon see "This coupon has expired"

Coupon Usage in the App

The coupon system is integrated into the ride booking flow. Here is how it appears at each stage:

  • Fare Summary Screen: A prominent "Apply Coupon" button appears below the fare breakdown
  • Coupon Entry: A text input field for the code with an "Apply" button. The code is case-insensitive
  • Valid Coupon: The discount is applied immediately. A green checkmark and the discount amount are displayed
  • Invalid Coupon: An error message explains why (expired, minimum not met, usage limit reached)
  • Applied State: The applied coupon is shown with its code and discount amount, with a "Remove" option

Coupon Analytics

The admin panel provides coupon usage analytics to help you track performance:

  • Total Uses: How many times the coupon has been applied across all users
  • Unique Users: How many distinct users have used the coupon
  • Total Discount Given: The aggregate discount amount provided
  • Average Discount Per Use: The average discount per application
  • Revenue Impact: Estimated revenue impact from the coupon

Welcome Coupon Strategy

Create a WELCOME coupon with a 20% percentage discount and a per-user limit of 1. This is an effective way to incentivize new user registrations and encourage first rides. Set a minimum fare of $5 to ensure profitability.

Monitor Coupon Usage

Check the coupon usage statistics in the admin panel regularly. If a coupon is being used more than expected, adjust the usage limit or per-user limit to control costs. Overuse of coupons can significantly impact revenue. Set up usage alerts for high-volume coupons.

Invalid Coupon Error Messages

When a user enters an invalid coupon code, the app displays one of these error messages:

Error Meaning
"Coupon not found" The entered code does not match any active coupon in the system
"This coupon has expired" The coupon's end date has passed
"Minimum fare not met" The ride fare is below the coupon's minimum fare requirement
"Usage limit reached" The coupon has reached its global usage limit
"You've reached your limit" The user has used this coupon the maximum number of times allowed
"Not valid for this service" The coupon does not apply to the selected service type
"Not valid for this vehicle" The coupon does not apply to the selected vehicle type
