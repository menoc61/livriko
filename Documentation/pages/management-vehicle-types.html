Vehicle Types

Vehicle types define the different ride and delivery options available to riders. Each vehicle type has its own image, icon, pricing, capacity, and zone assignments. Riders see these options when requesting a ride or delivery, and drivers are matched based on the selected vehicle type.

What Are Vehicle Types?

Vehicle types are the core building blocks of your service catalog.

Every ride request, rental booking, and parcel delivery in Livriko is tied to a vehicle type. The vehicle type determines what riders see in the app, how fares are calculated, which drivers can accept trips, and what images appear on the map.

Livriko Service Categories

Vehicle types can be assigned to one or more of the following service categories:

Cab (Ride)

Standard point-to-point rides. Includes Ride (on-demand), Intercity (long-distance between cities), and Schedule (advance booking) sub-services.

Freight

Heavy goods and large-item delivery. Suitable for moving furniture, appliances, construction materials, and bulk cargo. Vehicles with larger cargo capacity.

Parcel

Small package and document delivery. Ideal for couriers, e-commerce deliveries, and food logistics. Vehicles range from bikes to vans depending on parcel size.

Creating a Vehicle Type

Follow these steps to add a new vehicle category to your platform.

1. Navigate to Vehicle Types

Log in to the admin panel. Go to Livriko Management → Vehicle Types. You will see a list of all existing vehicle types with their status.

2. Click "Add New Vehicle Type"

Click the Add New Vehicle Type button. The vehicle type creation form opens with all configurable fields.

3. Upload Vehicle Image

Upload a clear, high-resolution image of the vehicle type. This image is shown to riders in the app when they select their ride option. Use a transparent PNG for best results. Recommended size: 512×512px.

4. Set Map Icon

Upload a small icon that represents the vehicle on the live map. This icon appears as the marker for drivers of this vehicle type. Recommended size: 64×64px. Use a distinctive shape or color to differentiate vehicle types on the map.

5. Configure Pricing & Services

Enter the vehicle name, base amount, vehicle charge, assign zones, select applicable services and categories, set commission and tax rates. See the field reference table below for detailed descriptions.

6. Save and Activate

Set the Status to Active and click Save. The vehicle type will now appear as an option in the rider app for the assigned zones.

Field Reference

Complete reference for every field on the vehicle type form.

Field Type Required Description
Image File upload Yes Vehicle image shown to riders in the app when selecting a ride option. Use a transparent PNG with a white or neutral background for consistency.
Map Icon File upload Yes Small icon displayed on the live map for drivers of this vehicle type. Helps riders visually identify their assigned driver on the map.
Name Text Yes Display name for the vehicle type (e.g., "Economy", "Comfort", "Premium", "Bike", "Van"). Must be unique and descriptive.
Base Amount Number Yes The starting fare charged at the beginning of every trip. This is a fixed amount regardless of distance or duration. Set to 0 if all pricing is distance-based.
Vehicle Charge Number Yes Additional per-trip charge for using this vehicle type. Added on top of the base fare and distance/time charges. Use for premium vehicle surcharges.
Zones Multi-select Yes Zones where this vehicle type operates. Only riders in selected zones will see this option. A vehicle type must be assigned to at least one zone to be visible.
Services Multi-select Yes Service types this vehicle supports: Ride (on-demand), Intercity (long-distance), Schedule (advance booking), Freight, and Parcel.
Service Categories Multi-select No Sub-categories for finer control. For example, under "Ride" you can specify "Standard" or "Premium". Useful for organizing vehicle types in the rider app.
Commission Percentage Yes Platform commission percentage deducted from each trip fare for this vehicle type. Applied after the base fare and distance charges are calculated.
Tax Percentage No Tax percentage applied to trips for this vehicle type. Calculated on top of the fare. Leave at 0 if taxes are handled at the zone or platform level.
Status Toggle Yes Active makes the vehicle type visible to riders and available for trips. Inactive hides it from the app without deleting the configuration.

Example Configuration

A sample vehicle type setup for a mid-tier ride option.

Configuration: "Comfort"

Vehicle Name:     Comfort
Image:            comfort-car.png (512x512, transparent)
Map Icon:         comfort-icon.png (64x64)
Base Amount:      $3.00
Vehicle Charge:   $1.50
Zones:            Paris, Lyon
Services:         Ride, Schedule
Service Categories: Standard
Commission:       20%
Tax:              10%
Status:           Active
Fare Calculation
For a 12 km, 20-minute Comfort ride in Paris with a base per-km rate of $0.80 and per-minute rate of $0.15:
$3.00 (base) + $1.50 (vehicle charge) + $9.60 (12 × $0.80) + $3.00 (20 × $0.15) = $17.10 before commission and tax.

Best Practices

Guidelines for configuring vehicle types effectively.

Image Consistency
Use a consistent visual style for all vehicle type images. If one vehicle uses a side-view illustration, all should use side-view illustrations. This creates a polished, professional rider experience.

Naming Conventions

  • Use descriptive names — "Economy Sedan" is better than "Type A". Riders need to understand what they are booking.
  • Keep names short — Names are displayed on small mobile screens. Aim for 1-2 words.
  • Use consistent naming across zones — If "Premium" exists in Paris, use the same name in Lyon for consistency.

Pricing Tips

  • Set base amounts low — A low base amount makes the ride feel more accessible. Compensate with per-km and per-minute rates.
  • Vehicle charge for premium options — Use the vehicle charge to create clear price differentiation between economy and premium tiers.
  • Commission flexibility — Higher-tier vehicles (Premium, SUV) can support higher commission rates since riders in these segments are less price-sensitive.

Service Assignment

  • Bikes and scooters should typically only be assigned to Ride and Parcel services.
  • Vans and trucks should be assigned to Freight and Parcel services.
  • Sedans and SUVs can be assigned to all services including Intercity and Schedule.
