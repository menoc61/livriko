Basic App Setup

This guide covers the essential configuration steps to get both the User and Driver apps running. These steps must be completed after installation and before building for production.

Environment Configuration

Both apps need to know the URL of your Livriko backend API, your Firebase project details, and your Google Maps API key. Edit the configuration file in each app to set these values.

User App: Open src/config/config.js

// src/config/config.js
export const BASE_URL = 'http://localhost:8000/api';   // Local development
// export const BASE_URL = 'https://yourdomain.com/api'; // Production

export const SOCKET_URL = 'http://localhost:8080';     // Reverb WebSocket
// export const SOCKET_URL = 'wss://yourdomain.com/reverb'; // Production

export const GOOGLE_MAPS_API_KEY = 'YOUR_GOOGLE_MAPS_API_KEY';

Driver App: Open src/config/config.js

// src/config/config.js
export const BASE_URL = 'http://localhost:8000/api';
// export const BASE_URL = 'https://yourdomain.com/api';

export const SOCKET_URL = 'http://localhost:8080';
// export const SOCKET_URL = 'wss://yourdomain.com/reverb';

export const GOOGLE_MAPS_API_KEY = 'YOUR_GOOGLE_MAPS_API_KEY';

API URL Suffix Required

Ensure the API URL ends with /api for both apps. Without the /api suffix, all API requests will fail with 404 errors. The backend Laravel route prefixes expect this path.

API Base URL

The API base URL points to your Livriko Laravel backend. For local development, use your machine's IP address rather than localhost when testing on a physical device.

# Find your local IP address
# macOS / Linux:
ifconfig | grep 'inet '

# Windows:
ipconfig

Then use the IP in your config:

export const BASE_URL = 'http://192.168.1.100:8000/api';

HTTPS in Production

For production deployments, always use HTTPS. iOS enforces App Transport Security and will block plain HTTP connections. Android 9+ also blocks cleartext traffic by default.

Firebase Initialization

Both apps require Firebase for push notifications and optional social login. Complete the Firebase setup before proceeding.

Download Firebase Config Files

Go to the Firebase Console, select your project, and download the config files for each platform.

Place Android Config

Copy google-services.json to Taxido_user/android/app/ and Taxido_driver/android/app/.

Place iOS Config

Copy GoogleService-Info.plist to Taxido_user/ios/ and Taxido_driver/ios/. Drag it into Xcode with "Copy items if needed" checked.

Enable Firebase Services

In the Firebase Console, enable Cloud Messaging for push notifications. Enable Authentication if using social login (Google, Apple, Facebook).

Google Maps SDK

Google Maps is required for map display, geolocation, and route calculation. See the Google Maps Setup guide for detailed instructions on obtaining and restricting your API key.

// src/config/config.js
export const GOOGLE_MAPS_API_KEY = 'AIzaSy...YOUR_KEY';

Add the key to the Android manifest in both apps:

<!-- android/app/src/main/AndroidManifest.xml -->
<meta-data
    android:name="com.google.android.geo.API_KEY"
    android:value="YOUR_GOOGLE_MAPS_API_KEY"/>

Push Notification Registration

On first launch, each app registers a Firebase Cloud Messaging (FCM) token with the Livriko backend. This token is used to send ride updates, driver arrival alerts, and promotional notifications.

// In your app initialization (App.js or auth service)
import messaging from '@react-native-firebase/messaging';

async function registerForPushNotifications() {
  const authStatus = await messaging().requestPermission();
  const enabled =
    authStatus === messaging.AuthorizationStatus.AUTHORIZED ||
    authStatus === messaging.AuthorizationStatus.PROVISIONAL;

  if (enabled) {
    const token = await messaging().getToken();
    // Send token to your backend
    await api.post('/device/register', { fcm_token: token });
  }
}

Authentication Flow

Livriko supports multiple authentication methods. The flow depends on your admin panel configuration:

Method User App Driver App Admin Config Required
Email/Password Yes Yes Enable in Settings → Auth
Phone OTP Yes Yes SMS gateway configured
Google Sign-In Yes Yes Firebase Social Login enabled
Apple Sign-In Yes iOS only Apple Developer account required

Launch Screen Configuration

The launch screen (splash screen) is the first thing users see. Customize it to match your brand:

  • Android: Edit android/app/src/main/res/drawable/splash_screen.xml and android/app/src/main/res/values/styles.xml
  • iOS: Edit ios/LivrikoUser/LaunchScreen.storyboard in Xcode. Update the background color and center image.

Run the Apps

Start the development servers for both apps after completing the above steps:

User App:

cd Taxido_user
npm install
npm run android    # For Android
npm run ios        # For iOS (Mac only)

Driver App:

cd Taxido_driver
npm install
npm run android    # For Android
npm run ios        # For iOS (Mac only)

Verify Connection

Open the App

Launch the User App on a device or emulator. The login screen should load (this confirms API connectivity).

Authenticate

Register a new account or log in with existing credentials. Verify you reach the home screen with the map.

Verify Map

Confirm the Google Map loads and shows your current location. This validates the Maps SDK configuration.

Test Driver App

Open the Driver App and repeat the verification steps. Ensure both apps can authenticate and communicate with the backend.

Setup Complete

If both apps can log in and display the map, the basic setup is complete. Proceed to build production APK/AAB files or configure iOS-specific settings.
