App Prerequisites

Before building the Livriko User App or Driver App, ensure your development environment meets all of the following requirements. Missing any prerequisite may cause build failures or runtime errors.

Warning

The Livriko backend (Laravel API) must be installed and running before you can fully test the mobile apps. See the Laravel Installation guide first.

Core Requirements

The following table lists all required tools, their minimum versions, and what each is used for. Install everything below before proceeding.

Requirement Version Notes
React Native 0.82.1 Cross-platform mobile framework
React 19.1.1 UI library (bundled with React Native)
Node.js >= 20 JavaScript runtime — LTS recommended
npm >= 10 Package manager (bundled with Node.js)
TypeScript ^5.8.3 Type-safe JavaScript development
Java JDK 17 Required for Android builds
Android Studio Latest stable Android IDE with SDK Manager and emulator
Android SDK Platform 36 Target API level for building
Xcode 15+ Apple IDE with iOS SDK (macOS only)
CocoaPods Latest iOS dependency manager (macOS only)
Watchman Latest File watching service for React Native hot reload

Android Development Tools

For building and running the apps on Android devices or emulators, you need the following components installed through Android Studio's SDK Manager:

Tool Version Purpose
Android Studio Latest stable IDE for Android development
Android SDK Platform 36 Target API level for building
Android SDK Build-Tools 36 Required for compiling native code
Android SDK Platform-Tools Latest ADB and debugging utilities
NDK (Side by Side) 27.1 Native Development Kit for C++ modules
Kotlin 2.1.20 Android language support
Gradle 8.9 Build automation tool

iOS Development Tools

For building and running the apps on iOS devices or simulators, you need a macOS machine with the following tools:

Tool Version Purpose
Xcode 15+ Apple IDE with iOS SDK
CocoaPods Latest iOS dependency manager
iOS Deployment Target 15.1 Minimum supported iOS version
Note

iOS development requires a Mac computer running macOS. iOS apps cannot be built on Windows or Linux.

Recommended IDE

Visual Studio Code is the recommended code editor for editing the Livriko app source code. Install the following extensions for the best development experience:

Extension Purpose
ES7+ React/Redux/React-Native snippets React Native code snippets
Prettier - Code formatter Automatic code formatting
ESLint JavaScript/TypeScript linting
React Native Tools Debugging and running React Native apps

Verification Commands

Run the following commands in your terminal to verify that all prerequisites are correctly installed and configured:

# Check Node.js and npm
node -v        # Should output v20.x.x or higher
npm -v         # Should output 10.x.x or higher

# Check Java (required for Android builds)
java -version  # Should show JDK 17

# Check Android SDK
echo $ANDROID_HOME  # Should point to your SDK directory

# Check ADB (Android Debug Bridge)
adb --version  # Should show platform-tools version

# Check Xcode (macOS only)
xcodebuild -version  # Should show Xcode 15+

# Check CocoaPods (macOS only)
pod --version  # Should show CocoaPods version

# Check Watchman
watchman --version  # Should show a version number
All checks passed?

If all the commands above return valid output, your environment is ready. Proceed to App Installation to clone and install the mobile apps.
